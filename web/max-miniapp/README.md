# `/app/` — не клиентский кабинет

С 2026-08-26 личный кабинет клиента **в MAX нет и не будет**.

| Что | Где |
|-----|-----|
| Переписка, подсказки, вложения | Личный чат MAX с ботом |
| Согласие, документы, оплата, статус | Веб-кабинет `cabinet.proverkastaza.ru` |

Страница `index.html` — заглушка-мост (на случай, если в настройках бота MAX ещё указан URL мини-приложения).  
Бот **не** должен предлагать `/app/` как кабинет: CTA только «Кабинет на сайте».

Legacy-скрипты `app.js` не подключаются и не являются продуктовым ЛК.
