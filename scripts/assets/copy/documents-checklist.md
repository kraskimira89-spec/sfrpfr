# Перечень документов для проверки стажа и назначения пенсии

**Канон для бота MAX и операторов.** Справочно; решение по учёту сведений принимает только СФР.  
Подача через СФР / МФЦ / Госуслуги — клиентом самостоятельно.  
Канал передачи документов: [`docs-channel-canon.md`](docs-channel-canon.md).  
Обновлено: 2026-08-31.

## 1. Базовый набор

- **Паспорт гражданина РФ** — личность, возраст, гражданство.
- **СНИЛС** — «зелёная карточка» или электронное уведомление о регистрации.

Если сведения о стаже и заработке уже полные в госсистемах, для оформления пенсии часто достаточно паспорта и СНИЛС — остальное СФР может запросить по межведомственным каналам. Для **проверки стажа сервисом** всё равно нужна актуальная **выписка ИЛС** (и трудовая / подтверждения по пробелам).

## 2. Что заказать на Госуслугах для проверки (названия услуг)

| Зачем | Как искать на Госуслугах (ориентир) | Примечание |
|---|---|---|
| Стаж, взносы, **ИПК**, сведения о назначенной пенсии (если уже назначена) | **«Выписка из лицевого счета в СФР»** (также: «Извещение о состоянии лицевого счета в СФР») | Раздел «Услуги» → «Пенсия» / поиск «ИЛС», «СЗИ-ИЛС» |
| Периоды работы по трудовому договору | **«Выписка из электронной трудовой книжки»** | «Справки и выписки» |
| Выплаты СФР за период (часто последние **12 месяцев** / за год) | **«Справка о выплатах СФР»** / «Справка о выплатах СФР за период» | В «Справки и выписки» → «Работа и пенсия»; период можно указать |
| Текущий размер назначенной пенсии | **«Справка о размере пенсии»** (или блок о назначенной пенсии **внутри выписки ИЛС**) | Актуальность названий сверяйте на портале на дату заказа |
| Назначенные выплаты на текущий момент | Справка / сведения о **назначенных выплатах** (или блок внутри ИЛС / справки о размере) | Для сверки «что назначили» рядом с банковской выпиской за 12 месяцев |

Интерфейс Госуслуг меняется — ориентируйтесь на официальное название услуги на дату обращения.

## 2.1. Банковская выписка (только по запросу специалиста)

- **Банковская выписка за 12 месяцев** по счёту, куда приходит пенсия — **не входит в базовый чек-лист**.
- Запрашивается только специалистом для узкой сверки начисленной и фактически полученной пенсии, с объяснением цели, периодом и отдельным согласием клиента.
- Не загружайте выписку, если специалист отдельно не объяснил, зачем она нужна; по возможности скройте нерелевантные операции.

## 3. Документы для подтверждения стажа (если в ИЛС неполно)

- Трудовая книжка (бумажная) или выписка из электронной трудовой.
- Архивные справки с мест работы (особенно при ликвидации).
- Приказы о приёме / увольнении, трудовые договоры.
- Ведомости начисления зарплаты, лицевые счета, штатные расписания.
- Выписки из приказов о переводах.
- Документы о переименованиях организаций.

## 4. Особые периоды и дополнительные документы

- **Военный билет** — служба в армии.
- **Количество детей / свидетельства о рождении** — периоды ухода до 1,5 лет (в т.ч. до 2002 г.); при утрате — повторное свидетельство или **справка о регистрации рождения / выписка ЕГР ЗАГС**. Универсальной «справки формы №4 о количестве детей» для всех обращений нет — берите то, что укажет СФР по конкретному пропуску.
- **Документы об опекунстве / попечительстве** — решение / постановление органа опеки (если ведёте дело за подопечного или подтверждаете статус); для стажа дополнительно нужны документы **по основанию ухода** (до 1,5 лет, инвалидность и т.д.).
- **Свидетельство о браке** — смена фамилии.
- **Документы об образовании** — при необходимости.
- **Льготный стаж** (северный, вредный / «горячий», педагогический, медицинский и т.п.) — СОУТ, архивные приказы, уточняющие справки о характере работ, списки профессий / производств — только по спорным периодам.

## 5. Пошагово: Госуслуги

1. Войти в **подтверждённую** учётную запись на gosuslugi.ru (чужой логин не использовать).
2. Заказать **выписку из лицевого счёта в СФР** → сохранить файл и дату формирования.
3. При необходимости — **выписку из электронной трудовой книжки**.
4. Если пенсия уже назначена и специалист запросил сверку выплат — **справку о выплатах СФР за период**, **справку о размере пенсии** / о назначенных выплатах и **банковскую выписку за 12 месяцев** (только после отдельного запроса в кабинете).
5. Заявление о **назначении пенсии** — отдельная услуга «Назначение пенсии», когда наступит право (обычно ближе к дате права).

Файлы сервису «Проверка стажа» можно прислать в личный чат MAX **после подтверждения согласия** на обработку ПДн.
Предпочтительно также через личный кабинет на сайте — так защищённее.

## 6. Если документов нет (ветвление)

| Ситуация | Действие |
|---|---|
| Нет Госуслуг / не подтверждена УЗ | Регистрация → подтверждение в МФЦ, Почтой России или УКЭП → затем шаги выше |
| Нет трудовой | Выписка из ЭТК на Госуслугах **или** дубликат через работодателя / архив |
| Нет паспорта | Сервис восстановления документов на Госуслугах («Жизненная ситуация») |
| Нет СНИЛС (бумага) | Номер в ЛК Госуслуг; бумага — СФР или МФЦ |
| Ликвидированное предприятие | Сначала ИЛС; при пробеле — госархив / архивные справки → в СФР на корректировку |
| Нет документов о детях / браке / образовании | ЗАГС / «Жизненная ситуация» на Госуслугах / повторные свидетельства |

Подготовку к пенсии лучше начинать за **1–2 года**; заявление о назначении — обычно **за месяц** до права.
