# Сервисные опросы после PDF (не маркетинг)

Канон: [ТЗ-29](../../../docs/specs/29-diagnosis-surveys.md).  
Не смешивать с согласием на ПДн и marketing consent.

## MAX: понятность плана (clarity)

**Когда:** PDF открыт, затем +48 часов (черновик → сотрудник подтверждает).  
Не вместе с выдачей PDF.

```text
Здравствуйте! Удалось ли посмотреть результат диагностики?
Нам важно убедиться, что план действий понятен.
```

Кнопки (callback `svy:{token}`, без case_id/ПДн):

- Всё понятно
- Нужна помощь с планом
- Есть вопрос по документу
- Пока не успел(а) посмотреть

## Ответы бота (коротко)

| Ответ | Реакция |
|---|---|
| Всё понятно | Спасибо; стадия acts_alone; later first_step (+10д) + quality (+7д) — [acts-alone](acts-alone-messages.md) |
| Нужна помощь | Передаём сотруднику |
| Есть вопрос | Сотрудник ответит; сканы/ПДн в чат не слать |
| Не успел | Напомним ещё раз (один повтор) |

## MAX: качество сервиса (quality)

**Когда:** после `clarity=clear`, +7 дней (черновик → approve).

```text
Здравствуйте! Коротко: насколько удобной и понятной оказалась
подготовка документов и плана? Это сервисный вопрос, не реклама.
```

Кнопки:

- Всё устроило
- В целом ок, есть замечания
- Не хватило ясности или поддержки

Публичный отзыв — отдельный сценарий, не из этого опроса.
