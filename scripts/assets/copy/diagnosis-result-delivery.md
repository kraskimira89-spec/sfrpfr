# После оплаты диагностики: срок, результат, следующий этап

**Канон:** [playbook-sales-clarity-funnel.md](../../../docs/marketing-sales/playbook-sales-clarity-funnel.md) **§4в**.  
**Стандарт PDF:** [playbook-diagnosis-result-standard.md](../../../docs/marketing-sales/playbook-diagnosis-result-standard.md).  
**Шаблон:** [`diagnosis-stazh-report.md`](../templates/diagnosis-stazh-report.md) · пример · `python scripts/build_diagnosis_report_pdf.py …`.  
**Цены:** диагностика 3 000 ₽ · подготовка **5 000 ₽** · сопровождение до подачи **8 000 ₽**.  
Оплата — начало обязательства. Сканы и подробности ПДн — только в кабинете.

**Название результата:** «Диагностика сведений о стаже и пенсионных документах» (информационно-документарный разбор).  
Не: «юридическое заключение», «расчёт пенсии».  
`doc_type`: **`diagnosis_report`**.

---

## 0–15 минут после оплаты

```text
Спасибо, оплату получили. Мы начинаем диагностику документов.

Следующий шаг — загрузить выписку ИЛС и трудовую книжку или сведения о трудовой
деятельности в личный кабинет на сайте. Предпочтительно так (защищённее); если файл уже в чат — примем.

После загрузки мы подтвердим получение и сообщим срок подготовки результата.
Решение о назначении или перерасчёте пенсии принимает СФР; наша задача —
проверить документы и подготовить понятный план действий.
```

Ссылка в кабинет — по процессу SFRFR (после оплаты / доступа).

---

## Срок

**Канон:** **3 рабочих дня** после полного комплекта (ИЛС + трудовая / сведения о трудовой; плюс справки — по ситуации).  
Для сложности **C/D** — согласовать срок с владельцем **до** обещания клиенту.

```text
После получения полного комплекта документов подготовим диагностику
в течение 3 рабочих дней.
```

### Комплект неполный

```text
Сейчас получили выписку ИЛС. Для начала проверки ещё нужна трудовая книжка
или сведения о трудовой деятельности. После загрузки мы подтвердим комплект
и назовём срок подготовки диагностики.
```

Не запускать срок, пока минимальный комплект не в кабинете.  
Не говорить «скоро» без числа дней.

## Ops: от шаблона до кабинета

```text
1. Заполнить scripts/assets/templates/diagnosis-stazh-report.md (копия вне git с ПДн)
2. python scripts/build_diagnosis_report_pdf.py filled.md -o out/diag.pdf
3. Admin → дело → Диагностика → загрузить PDF (тип «Результат диагностики»)
4. QA-чеклист из playbook-diagnosis-result-standard.md
5. MAX: сообщение ниже + ссылка в кабинет
```

Без PDF в кабинете диагностику **не** считать выданной клиенту (findings в UI — дополнение, не замена).

## Каркас документа (минимум)

1. Короткий итог на 1-й странице  
2. Перечень изученных документов + фраза «только по перечисленным»  
3. Таблица периодов  
4. 3–5 вопросов/расхождений  
5. План действий (кто / режим / срок)  
6. Что дальше (сам / с сервисом 5k|8k / не входит)  
7. Дисклеймер СФР  

Полная структура и запреты формулировок — в стандарте продукта.

## Выдача результата в MAX

Сразу — **навигация** (не отзыв). Полный канон: [`diagnosis-feedback-messages.md`](diagnosis-feedback-messages.md).

```text
Диагностика готова и доступна в защищённом кабинете на сайте. В документе выделены:
что проверено, какие вопросы требуют уточнения и какой следующий шаг рекомендуем.

После ознакомления напишите, пожалуйста, одним сообщением:
1 — всё понятно
2 — нужна помощь разобраться с планом
3 — есть вопрос по документу
```

CRM: этап «Диагностика выдана» · PDF `diagnosis_report` · `pdf_issued_at` · next step + дата.  
Через 2–3 / 10–14 дней — сервисные касания (черновик); отзыв Яндекса — только после положительной оценки ([ТЗ-27](../../../docs/specs/27-diagnosis-pdf-feedback.md), ТЗ-19).

## Оффер шага 2 / 3 (только при реальном объёме)

Сначала 2–3 конкретных действия из диагностики, затем выбор «сам / с нами», затем цена **5 000** или **8 000**.

Типовой кейс «нужен архив / правопреемник» → [playbook-archive-request-prep.md](../../../docs/marketing-sales/playbook-archive-request-prep.md) · скрипты [`archive-request-offer.md`](archive-request-offer.md) (тариф подготовки **5 000 ₽** за один комплект).

```text
По результатам диагностики нужно подготовить [действие 1], [действие 2], [действие 3].

Вы можете сделать это самостоятельно по подготовленному плану.
Если хотите, мы можем взять на себя документарную часть: перечень приложений,
сводную таблицу и проект обращения. Это отдельная услуга; состав и стоимость
согласуем до начала работы.
```

```text
По этому объёму подходит [подготовка документов — 5 000 ₽ /
сопровождение до подачи — 8 000 ₽].
Решение принимает СФР, поэтому мы не обещаем итоговый перерасчёт.
Мы отвечаем за подготовку согласованного комплекта документов и проекта обращения.
```

Не использовать публично **10 000 / 25 000** и формулировку «под ключ» как тариф.  
Цену следующего этапа не выдавать в PDF как уже согласованную без согласия клиента.

## Когда не предлагать платный этап

```text
По текущим документам платное сопровождение вам не требуется.
Выполните два шага из плана; если получите ответ СФР или появятся дополнительные
документы, вернитесь — посмотрим, нужен ли следующий этап.
```

Не предлагать, если: нет расхождений · хватает бесплатного шага на Госуслугах · достаточно инструкции · нет базы для обращения · нет согласия / понимания · этап не добавляет ценности.

## Самопроверка эксперта / оператора

1. Документ понятен без звонка?  
2. Есть конкретные действия, даты, документы?  
3. Честно ли объясняю, зачем 5k/8k здесь?  
4. Есть выбор: сам или заказать?  
5. Смог бы так же для близкого человека?  
6. PDF загружен в кабинет как `diagnosis_report`?
