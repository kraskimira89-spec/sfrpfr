# Manrope (локально)

Шрифт **Manrope** (SIL Open Font License) для публичного сайта WordPress.

- Источник: `@fontsource/manrope@5.2.5` (woff2, начертания 400/500/600/700, latin + latin-ext + cyrillic + cyrillic-ext).
- Лицензия: `OFL.txt`.
- CSS: `sfrfr-manrope.css` (подключается в начале `sfrfr-landing.css`).
- На VPS копируется в `/wp-content/uploads/sfrfr/fonts/manrope/`.

Кабинеты (`apps/cabinet`, `apps/admin`) уже используют npm-пакет `@fontsource/manrope` — без Google Fonts.
