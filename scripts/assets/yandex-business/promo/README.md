Форма отзыва: https://yandex.ru/sprav/82469923047/reviews/add/  
Бейдж рейтинга (виджет): `https://yandex.ru/sprav/widget/rating-badge/82469923047?type=rating`

| Файл | Назначение |
|------|------------|
| `qr-review.png` | QR на форму отзыва (для MAX / сайта) |
| `card.pdf` | Визитка с QR |
| `booklet.pdf` | Буклет / пирамидка с QR |
| `review-url.txt` | Та же ссылка текстом |

На сайте:

- `/kontakty/` — бейдж + ссылка + QR;
- футер всех страниц — бейдж рядом с ИКС.

Правила просьб: `../review-request-templates.md` — мягкий тон, без навязчивости.
