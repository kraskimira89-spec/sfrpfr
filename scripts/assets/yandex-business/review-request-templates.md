# Шаблоны просьбы об отзыве (MAX) — мягкий тон

**Ссылка на форму:** https://yandex.ru/sprav/82469923047/reviews/add/  
**QR:** `scripts/assets/yandex-business/promo/qr-review.png` (и `assets/qr.png`)  
**Визитка / буклет для печати:** `promo/card.pdf`, `promo/booklet.pdf`  
Источник правил: https://direct.yandex.ru/base/articles/kak-pravilno-motivirovat-klientov-ostavlyat-otzyvy

Принцип: **не навязывать**. Одна короткая просьба; напоминание — только по желанию оператора и не раньше чем через 3 дня; при любом «нет» — сразу остановиться.

---

## Когда отправлять

Только после того, как клиент получил результат **работы сервиса** (план, чек-лист, черновики) и диалог спокойный.  
Не просить в момент отказа, спора или ожидания решения СФР.

**Автоматически:** при статусе дела `completed` бот один раз шлёт мягкую просьбу в MAX  
(см. `maybe_send_soft_review_ask`). Повторно система **не** пишет.  
**Вручную:** оператор может один раз напомнить не раньше чем через 3 дня — шаблон ниже.

---

## Вариант A — основной (рекомендуется)

Коротко. Можно приложить файл `qr-review.png` (если MAX позволяет вложение картинки).

```text
Спасибо, что обратились в «Проверку стажа».

Если захотите и будет удобно — можно оставить короткий отзыв о нашей работе (необязательно):
https://yandex.ru/sprav/82469923047/reviews/add/

Если не хотите — ничего писать не нужно. Больше не будем напоминать.
```

---

## Вариант B — ещё короче

```text
Если будет минута и желание — отзыв о сервисе можно оставить здесь (по желанию):
https://yandex.ru/sprav/82469923047/reviews/add/
```

---

## Направляющие вопросы — только если клиент спросил «что написать?»

Не присылать вместе с первой просьбой по умолчанию.

```text
Можно коротко своими словами, например:
— чем мы помогли (сверка, документы, план);
— что было удобно или наоборот.
Оценку и текст выбираете вы. Решение СФР в отзыве описывать не обязательно.
```

---

## Напоминание (не чаще одного раза, не раньше чем через 3 дня)

Отправлять **только** если:
- клиент не отказался;
- не было негатива;
- оператор считает уместным.

```text
Здравствуйте. Если отзыв всё ещё актуален и удобно — ссылка та же:
https://yandex.ru/sprav/82469923047/reviews/add/

Если нет — просто не отвечайте, больше не напомню.
```

---

## Если клиент против / молчит после напоминания

```text
Хорошо, отзыв не нужен. Мы на связи в MAX, если понадобится помощь по документам.
```

При молчании после напоминания — **не писать третий раз**.

## Печатные материалы

| Файл | Где использовать |
|------|------------------|
| `card.pdf` | Визитка / вложение в письмо родственнику по просьбе клиента |
| `booklet.pdf` | Распечатка «пирамидка/буклет» при личной встрече (редко) |
| `qr-review.png` | MAX, сайт `/kontakty/`, соцсети |

Текст на макетах Яндекса уже корректный: благодарность + переход по QR, без бонусов.

---

## Чего не писать

- «Поставьте пять звёзд» / «обязательно оцените»
- бонус, скидка, подарок за отзыв или скрин
- серия напоминаний, звонки «ради отзыва»
- просьба сотрудникам / родственникам / «своим»
- «напишите, что пенсию повысили»
