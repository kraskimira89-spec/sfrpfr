# Мастер задач SFRFR

Плагин создаёт задачи в очередях SFRFR, PUB и FUNNEL с нужными тегами и проверкой текста на признаки ПДн.

## Как пользоваться

1. Откройте пункт **Мастер задач SFRFR** в навигации Трекера.
2. Выберите очередь.
3. При необходимости укажите обязательные теги (для PUB и FUNNEL).
4. Проверьте название и описание, затем нажмите **Создать задачу**.

Если плагин найдёт в тексте телефон, email или СНИЛС, покажет предупреждение. Решение о пенсии и перерасчёте принимает только СФР; плагин только помогает завести внутреннюю задачу.

## Очереди

| Очередь | Назначение |
|---------|------------|
| SFRFR | продукт, infra, agents |
| PUB | публикации |
| FUNNEL | ops воронки без ПДн |

## Ограничения

Не вставляйте в задачу СНИЛС, ИЛС, сканы и другие персональные данные клиентов.
