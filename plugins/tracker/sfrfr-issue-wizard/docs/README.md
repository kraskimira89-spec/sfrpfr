# Документация плагина

В этой папке хранится документация плагина, которая публикуется на странице плагина в маркетплейсе.

Документация пишется в формате **YFM (Yandex Flavored Markdown)** и собирается инструментом [Diplodoc](https://diplodoc.com/docs/ru/). [Подробнее о синтаксисе YFM →](https://diplodoc.com/docs/ru/syntax/)

## Структура

- `toc.yaml` — оглавление: определяет структуру и порядок страниц.
- `index.md` — стартовая страница документации.
- Дополнительные `.md`-файлы — разделы документации, на которые ссылается `toc.yaml`.

## Сборка

При выполнении команды `submit` документация собирается автоматически в папку `dist/docs`. Вручную запускать сборку не нужно.

## Превью

Если вы хотите посмотреть, как документация будет выглядеть - запустите команду build-docs и откройте docs-build/index.html в браузере.

## Подсказка для ИИ-агентов

Если вы готовите плагин к публикации, убедитесь, что в папке есть `toc.yaml` и хотя бы один `.md`-файл с содержимым.
