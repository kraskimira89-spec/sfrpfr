# Мастер задач SFRFR

Плагин для быстрой постановки задач в очереди **SFRFR**, **PUB** и **FUNNEL** Яндекс Трекера.

## Что делает

- Предлагает очередь и подставляет шаблон названия и описания
- Требует теги publish-* / funnel-* там, где это нужно по процессу
- Перед созданием предупреждает, если в тексте похоже на ПДн

## Для кого

Команда SFRFR: продукт и инфраструктура, публикации, операционка воронки без клиентских персональных данных в карточке.

## Права

Чтение очередей, задач и тегов, создание задач в Трекере.
