# Брифы на визуализацию

Сюда кладём задания на символьные изображения. Шаблон ниже копировать в новый файл
`viz-<slug>.md` после утверждения ассоциации в `../associations/`.

Утверждённые файлы изображений — в `../assets/`.

---

## Шаблон брифа

```text
Название:
Связанная ассоциация: associations/assoc-….md
Формат: иконка / обложка / баннер / печать
Размер / пропорции:
Главный символ (один):
Настроение:
Текст на изображении (если нужен):
Цвета:
Запреты:
Критерий приёмки (3 секунды):
Статус: черновик / на согласовании / утверждено
Файл в assets/:
```
