# Ассоциация: Сопровождение

**Услуга:** Сопровождение по документам и этапам (10 000 ₽)  
**Смысл одной фразой:** рядом на пути подготовки — без подмены клиента в СФР.

## Ценности

Бережность, самостоятельность клиента, аккуратность.

## Ассоциации

ступени пути, проводник (не судья), папка этапов, черновик заявления,
рука передаёт чек-лист клиенту, мост «мы готовим — вы подаёте», безопасный
пешеходный переход, взрослая рука рядом, цифровая навигация без лишения самостоятельности.

## Запрещённые образы

агент «подаст за вас», подпись за клиента, очередь в окошко СФР от нашего лица,
пожилой человек в роли беспомощного ребёнка, назидательный сопровождающий.

## Цвет / фактура

Синий + зелёный; ритм ступеней / нумерованный путь.

## Предлагаемый символ (словесно)

Стилизованный переход из трёх безопасных полос:
«документы → черновик → ваша подача»; рядом — две равноправные взрослые фигуры,
одна помогает другой ориентироваться в цифровом пути.
