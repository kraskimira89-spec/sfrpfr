# Ассоциация: Северный стаж

**Сегмент / страница:** проверка северного стажа, районный коэффициент  
**Смысл одной фразой:** северные периоды и коэффициент сверять отдельно, не смешивая основания.

## Ценности

Ясность, аккуратность, честность границ.

## Ассоциации

северный свет, два отдельных списка («стаж» / «коэффициент»), карта-метка без клише,
холодный воздух + тёплый стол документов, «не путать в одну кучу».

## Запрещённые образы

медведь/ушанка как шутка, ледяной ужас, «север = автоматом больше пенсия».

## Цвет / фактура

Холодный светлый фон + фирменный синий; зелёный только как акцент «проверено».

## Предлагаемый символ (словесно)

Две колонки-карточки рядом: «периоды» и «коэффициент», соединённые тонкой линией сверки.
