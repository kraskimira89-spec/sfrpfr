# Утверждённые визуальные активы бренда

Сюда помещать только согласованные файлы (SVG, PNG, PDF-макеты без ПДн).

Пока папка-заготовка: новые файлы именовать `viz-<slug>-<variant>.ext` и ссылаться
из соответствующего брифа в `../visualizations/`.

Перед утверждением сверять с [brand-platform-v2.md](../brand-platform-v2.md) §9–10:
партнёрство за столом, без опеки и без обещания результата.
