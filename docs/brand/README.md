# Brand — визуализация смыслов

Папка для бренд-платформы, смыслов, ценностей и ассоциативных рядов,
из которых создаются символьные изображения этапов и услуг.

## Зачем 

Из **вида деятельности** организации выявляем:

1. смыслы (зачем существуем);
2. миссию (кому и какую пользу даём);
3. ценности (на что опираемся и чего не делаем);
4. ассоциативный ряд (образы, метафоры, символы);
5. визуализацию (символьные изображения этапа или услуги).

Это **визуализация смыслов** / **визуализация корпоративной идентичности**:
глубинная основа переводится в понятные визуальные символы без потери смысла.

Связанные понятия:

- **корпоративный брендинг** — целостный образ: визуал, смыслы, культура и сервис;
- **бренд-платформа** — задокументированная система смыслов, ценностей и принципов.

## Как пополнять

1. Зафиксировать вид деятельности и границы (что делаем / чего не обещаем).
2. Пройти шаги методологии и обновить бренд-платформу.
3. Для нового этапа или услуги — карточка в `associations/`.
4. Для картинки, иконки, иллюстрации — бриф в `visualizations/`.
5. Утверждённый файл положить в `assets/` и сослаться из брифа.

Не хранить здесь ПДн клиентов, рекламные токены и пароли.
