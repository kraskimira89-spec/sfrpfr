# Промпт для агента: реализация бренда v2 (P0)

Скопируй **весь блок ниже** в новый чат Cursor (Agent). Сообщение самодостаточное.

---

```text
Ты — агент внедрения бренда на сайте «Проверка стажа» (репозиторий SFRFR / proverkastaza.ru).

## Задача
Реализовать этап **P0** из ТЗ: вшить голос бренда v2 «Цифровая рука помощи» в приоритетные HTML-страницы витрины **без поломки стилей и без загромождения**.

Полное ТЗ: `docs/brand/spec-brand-rollout.md`
Канон формулировок: `docs/brand/brand-platform-v2.md`
Позиция о подаче: `scripts/assets/copy/submission-position.md`
Стили (не ломать): `scripts/assets/sfrfr-landing.css`

Сначала прочитай эти 4 файла. Не импровизируй бренд поверх них.

## Обязательные правила
1. Отвечай на русском. Минимальные точечные правки.
2. Не редизайнить сайт. Не менять палитру, шрифты, `--sfrfr-*`, сетку hero.
3. Не добавлять новые секции, бейджи, слайдеры, фото-баннеры, emoji-ряды, «блок миссии».
4. Не трогать оферту/privacy/cookies. Не массово править блог и `situations` (blog-manual-only).
5. Канон подачи не ослаблять и не «улучшать». Полная или короткая формула из submission-position.md.
6. Запрещены на витрине: гарантия выплат, «подадим за вас», опека, вина, «сыновий долг», «цифровой двойник», герб/триколор/имитация Госуслуг.
7. Primary CTA в MAX (`{{MAX_BTN_URL}}`) не ломать. Не заменять единственную главную кнопку на абстрактную «Начать проверку», если это рвёт воронку; доп. кнопку добавляй только если ряд CTA не перегружен (см. ТЗ).
8. P2 (картинка семьи за столом) **не делать** в этом задании, пока нет утверждённого файла в `docs/brand/assets/`. SVG чек-листа на главной оставить.
9. После правок: коммит на русском (кратко «почему»), `git push origin HEAD`, при необходимости обновить WP сидом главной/trust (как принято в репо). Не запускать массовый seed блога.
10. Запиши краткую историю в `docs/history/YYYY-MM-DD-brand-rollout-p0.md`.

## Что сделать (P0)

### A. `scripts/assets/sfrfr-home.html`
- `h1` → **Проверим трудовую историю вместе.**
- `.sfrfr-hero__lead` → смысл v2: ясность для родителей + спокойствие для семьи; плюс подзаголовок про сведения о стаже / документы / следующий шаг. Один-два коротких абзаца, без канцелярита.
- Disclaimer / доверие: можно выровнять к «Вы решаете сами. Мы помогаем подготовиться. Решение принимает СФР.» + сохранить «не являемся СФР» при необходимости.
- Карточка про родственника в блоке `#komu` — голос «рядом / вместе», без опеки.
- Не раздувать hero: identity, channels, nav, illustration — структура DOM как сейчас.

### B. `scripts/assets/trust/pomoch-rodstvenniku-proverit-stazh.html`
- Lead в духе: «Будьте рядом с родителем — спокойно разберитесь в цифровых вопросах вместе.»
- Канон подачи — один раз, без двойного простынного дубля.
- Лёгкая правка карточек «Кому подходит» под голос v2.
- CTA на MAX сохранить.

### C. `scripts/assets/trust/proverka-stazha.html`
- Мягко вплести «трудовая история» / ясность в lead, не меняя смысл услуги и канон.

### D. По желанию (если быстро и безопасно)
- Точечно `kak-rabotaem.html` / `tarify.html` / `proverka-severnogo-stazha.html` — только явный канцелярит или риск обещания результата. Без новых блоков.

## Редакторский тест (на каждую новую фразу)
«Сохраняет ли эта фраза уважение к родителю и делает ли следующий шаг понятнее?»
Если давит, стыдит, обещает результат или звучит как ведомство — переписать.

## Критерии готовности
- [ ] H1 и lead главной соответствуют v2.
- [ ] Страница родственников — «рядом/вместе», без опеки.
- [ ] Канон подачи на месте.
- [ ] CSS/hero grid не сломаны; новых маркетинговых секций нет.
- [ ] Блог пакетом не тронут.
- [ ] Коммит + push; история в docs/history; в ответе — список изменённых файлов и цитата нового h1/lead.

## Что вернуть в чат
1. Кратко: что сделано в P0.
2. Список файлов.
3. Diff-фрагменты только изменённых кусков (не целые файлы).
4. Что сознательно не трогали (P2, блог, CSS).
5. Если нужен сид WP — какая команда и статус.

Начни с чтения ТЗ и канона, затем правь файлы.
```

## Как пользоваться

1. Открой новый чат Agent.
2. Вставь блок из fenced `text` выше целиком.
3. При необходимости добавь одной строкой: «Сделай только P0» или «После P0 сразу задеплой сидом».
4. P2 (визуал семьи) — отдельным чатом после появления ассета в `assets/`.
