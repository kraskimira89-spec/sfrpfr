# Методика: визуальная метафора публикации (два слоя)

**Назначение:** обложки и иллюстрации к постам (блог, VK, MAX, Директ), не замена
этапов 0–6 платформы услуг в [methodology-meaning-visualization.md](methodology-meaning-visualization.md).

**Пакет:** [prompts/visual/](../../prompts/visual/README.md)  
**Агент:** [prompt-agent-brand-visual-metaphor.md](prompt-agent-brand-visual-metaphor.md)  
**Guardrails:** [prompts/visual/brand-guardrails.md](../../prompts/visual/brand-guardrails.md)

---

## Правильная формула (7 шагов смысла)

```text
1. Тема публикации
2. Практическая проблема человека
3. Эмоция проблемы
4. Целевое состояние после прочтения
5. Визуальный мост: предмет или сцена
6. Действие человека / что происходит с предметом
7. Ограничения платформы и бренда
```

Между «предметом» и промптом обязательно: **что происходит с предметом?**
Не «папка», а «папка с аккуратно разложенными документами, рядом ручка и чек-лист».

---

## Два слоя автоматизации

### 1. Контентный слой — VisualMatrix (JSON)

Единый объект смысла (не текст под одну нейросеть). Поля: topic, audience, problem,
emotionBefore, desiredState, coreMessage, metaphor, action, subject, visualStyle,
mood, brandPalette, composition, textSafeArea, platform, aspectRatio, prohibitions.

Схема: `prompts/visual/visual-matrix.schema.json`.  
Примеры: `prompts/visual/examples/*.json`.

### 2. Рендер-слой — compiler

`compileVisualPrompts(matrix)` →:

1. Midjourney prompt (короткий, образный) + параметры `--ar` / `--stylize` / `--chaos` / `--no`
2. GPT Image / DALL·E prompt (подробное ТЗ: фон → объект → действие → детали → ограничения)
3. negative prompt
4. alt-текст (до ~180 символов)
5. editor_note (для сотрудника) — в ответе агента

Код: `prompts/visual/compiler.ts` (без вызова Image API).

## Конвейер

```text
Тема публикации
→ агент строит матрицу (и/или сразу compiled JSON)
→ валидатор: brand-guardrails
→ человек утверждает metaphor + core_message
→ генерация изображения
→ человек утверждает кадр
→ публикация
```

**Не публиковать** визуал без человеческой проверки.

## Форматы каналов

| Канал | aspect_ratio |
|-------|----------------|
| Статья / Дзен / Яндекс-обложка | 16:9 |
| Карточка сайта | 4:3 |
| MAX / квадратный пост | 1:1 |
| Сторис / вертикаль | 9:16 |
| Яндекс Директ | явно в матрице после сверки ТТ (часто 1:1, 4:3, 3:4, 16:9) |

Заголовок накладывается **вне** картинки (редактор публикации).

## Матрица ассоциаций (шпаргалка)

| Проблема | Эмоция | Целевое | Метафора | Действие |
|----------|--------|---------|----------|----------|
| Не понимает ИЛС | Растерянность | Ясность | Карта / лупа | Отмечает понятные пункты |
| Пропал период | Тревога | Контроль | Нить / пазл | Нить соединяется, рядом папка |
| Нет документов организации | Бессилие | Маршрут | Архивный ящик | Карточка периода + путь |
| Боится передать документы | Недоверие | Безопасность | Папка / ячейка | В кабинет сайта; чат — связь |
| Хаос бумаг | Перегрузка | Порядок | Четыре папки | Руки раскладывают листы |
| Родственник помогает | Неуверенность | Поддержка | Две пары рук | Вместе смотрят чек-лист |
| Ответ СФР | Неопределённость | План | Дорожная карта | Письмо + шаги 1–2–3 |
| Архивный запрос | Поиск | Надежда без обещаний | Каталог / коробка | Лупа, карточка, стрелка |

## Критерий приёмки кадра

1. За 3 секунды понятен переход «проблема → ясность/порядок».
2. Есть действие в кадре.
3. Нет ПДн, гербов, денег, обещания результата, беспомощности.
4. Есть свободная зона под заголовок.
5. Редакторский тест v2: уважение к родителю + понятный следующий шаг.

## Слоган дуги (три слова)

К каждому кадру — короткая формула **Проблема → Прояснение → Целевое**:

| Обложка | Слоган |
|---------|--------|
| Сбор документов | Хаос → Ясность → Порядок |
| Архивная справка | Тупик → Маршрут → Надежда |
| Безопасная передача | Спешка → Защита → Уверенность |
| После чек-листа | Пауза → Уважение → Возврат |
| Родственник помогает | Неуверенность → Рядом → Поддержка |

Слоганы в брифах `viz-meta-*.md` и в [prompts/visual/examples/README.md](../../prompts/visual/examples/README.md).
