## Быстрый указатель «что читать под задачу SFRFR»

| Задача | Смотреть разделы |
|--------|------------------|
| Настроить воронку и права | Начиная работу → воронка; Пользователи |
| Поля CASE_ID / канал | Поля; Карточка; амоМаркет |
| Лид с сайта | Формы **или** наш API (предпочтительно API) |
| MAX в amo vs наш бот | Неразобранное → MAX; Чаты |
| Этап в amo → событие в SFRFR | Digital → webhook |
| Не класть сканы в amo | Файлы — осознанно **не** подключать к делу |
