# Шпаргалка оператора: новый лид в amo

**Воронка:** «Проверка стажа» · **Этап:** «Новый лид»  
**Полная инструкция:** [playbook-operator-amo-card.md](playbook-operator-amo-card.md) · [playbook-funnel-checklists-automation.md](playbook-funnel-checklists-automation.md)

---

## За 30 секунд

1. **ID дела (SFRFR)** + **Ссылка на дело SFRFR** + **Продолжить диалог MAX** (кликабельные поля).
2. **CONSENT** и **Канал** — можно ли писать; MAX / телефон / сайт.
3. Задача **«Первый контакт»** — выполнить чеклист → **«Связались»**.

> В amo — связь и статусы. Сканы, СНИЛС, ИЛС — **только в кабинете SFRFR**.

---

## Первый контакт (SLA: тот же рабочий день)

| # | Действие |
|---|----------|
| 1 | **Продолжить диалог MAX** (поле-ссылка) или канал телефон/email |
| 2 | Текст первого сообщения — [playbook-operator-first-message-max.md](playbook-operator-first-message-max.md) |
| 3 | Скрипт: за себя / родственник; пенсия; фокус; ИЛС; трудовая |
| 4 | Заметка в amo (шаблон ниже) — **без** СНИЛС, паспорта, OCR, файлов |
| 5 | Задачу закрыть → этап **«Связались»** |

**MAX:** имя «MAX 12345678» = ID пользователя; телефона часто нет — пишем в MAX.

**Подача:** готовим документы и план — подаёт клиент через СФР/МФЦ/Госуслуги; решение принимает только СФР.

## Дальше по воронке (вручную)

| После | Этап amo |
|-------|----------|
| Квалификация + «Тип проблемы» | Квалифицирован |
| Оффер 3 000 ₽, ссылка в кабинет | Диагностика предложена |
| Оплата (авто из SFRFR) | Диагностика оплачена |
| Документы в кабинете | Документы в кабинете |

Тарифы: диагностика **3 000 ₽** · подготовка **5 000 ₽** · сопровождение **8 000 ₽**. Без обещания перерасчёта.

## Шаблон заметки (копировать)

```text
Связь: [MAX / дозвон] — [дата]
Кейс: [за себя / родственник]; пенсия: [уже / ещё нет]
Фокус: [ИЛС / север / отказ СФР]

Документы (только статус):
- ИЛС: нет | запрошен | в кабинете
- Трудовая / эл. сведения: …
- Согласие/кабинет: …

Следующий шаг: …
Дело: SFRFR_CASE_URL
```

---

## Можно / нельзя

| ✅ | ❌ |
|----|-----|
| Статусы документов в заметке | Сканы и файлы в amo |
| Смотреть документы в кабинете | СНИЛС, паспорт, OCR в CRM |
| LOSS с «Причиной потери» | Отказ без причины |
| Цены с сайта | Обещание суммы пенсии / перерасчёта |
