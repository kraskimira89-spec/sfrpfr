# Шпаргалка оператора: новый лид в amo

**Воронка:** «Проверка стажа» · **Этап:** «Новый лид»  
**Полная инструкция:** [playbook-operator-amo-card.md](playbook-operator-amo-card.md) · [playbook-funnel-checklists-automation.md](playbook-funnel-checklists-automation.md)

---

## За 30 секунд

1. **ID дела (SFRFR)** + **Ссылка на дело SFRFR** — открыть admin.
2. **MAX user_id** + **Как ответить в MAX** — не ссылка на бота.
3. Первое сообщение — [playbook-operator-first-message-max.md](playbook-operator-first-message-max.md) (человек → польза → диагностика).

> В amo — связь и статусы. Сканы, СНИЛС, ИЛС — **только в кабинете SFRFR**.  
> Продаём ясность и план, не прибавку к пенсии. Первый оффер — **3 000 ₽**.

## Первый контакт (SLA: тот же рабочий день)

| # | Действие |
|---|----------|
| 1 | amo **Чаты** (виджет MAX) **или** admin → «Написать в MAX» |
| 2 | Текст первого сообщения — [playbook-operator-first-message-max.md](playbook-operator-first-message-max.md) |
| 3 | Скрипт: за себя / родственник; пенсия; фокус; ИЛС; трудовая → оффер диагностики |
| 4 | Заметка в amo (шаблон ниже) — **без** СНИЛС, паспорта, OCR, файлов; **next step + дата** |
| 5 | Задачу закрыть → этап **«Связались»** |

### Как ответить клиенту в MAX (важно)

**Ссылка на бота** (`max.ru/..._bot`) открывает **ваш** чат с ботом, не переписку клиента. Прямого URL на диалог клиента в MAX нет.

| Способ | Действие |
|--------|----------|
| **1. amo Чаты (основной)** | Виджет MAX + **«Проверка стажа-личный бот»** → **Чаты** amo — [ops-amocrm-max-widget.md](ops-amocrm-max-widget.md) |
| **2. Admin (запасной)** | **Диалог MAX (ответ клиенту)** или **Ссылка на дело SFRFR** → «Написать клиенту в MAX» |
| **3. MAX Business** | **«Проверка стажа-личный бот»** → **Диалоги** → **MAX user_id** |

Поле amo **«Как ответить в MAX»** — краткая подсказка, не ссылка.

## Шаблон заметки (копировать)

```text
Связь: [MAX / дозвон] — [дата]
Кейс: [за себя / родственник]; пенсия: [уже / ещё нет]
Фокус: [ИЛС / север / отказ СФР]

Документы (только статус):
- ИЛС: нет | запрошен | в кабинете
- Трудовая / эл. сведения: …
- Согласие/кабинет: …

Следующий шаг: …
Дата шага: …
Ответственный: …
Дело: SFRFR_CASE_URL
```

Возражения / цена: [playbook-sales-clarity-funnel.md](../marketing-sales/playbook-sales-clarity-funnel.md) §4–§5.  
Тарифы: диагностика **3 000 ₽** · подготовка **5 000 ₽** · сопровождение **8 000 ₽**. Без обещания перерасчёта. Шаг 2–3 — после диагностики.  
Не оправдывать цену; не скидка «на эмоциях».

## Можно / нельзя

| ✅ | ❌ |
|----|-----|
| Статусы документов в заметке | Сканы и файлы в amo |
| Смотреть документы в кабинете | СНИЛС, паспорт, OCR в CRM |
| LOSS с «Причиной потери» | Отказ без причины |
| Цены с сайта; next step + дата | Обещание суммы пенсии / перерасчёта |
| Чек-лист при «дорого»/«нет денег» как **первый шаг** | «Ну тогда возьмите бесплатный…»; спор; скидка на эмоциях |
| «Ожидаем клиента» + 2 касания (§5в) | Дожим / LOSS сразу после молчания; реклама без согласия |
| Один вопрос о препятствии + микроворонка (§5г) | Пять вопросов подряд / сразу продавать диагностику |
| Триггер → выбор «диагностика или чек-лист» (§4б) | «Будете покупать?» / ссылка на оплату до согласия |
| После «да»: подтверждение → оплата → кабинет | Молчание после согласия / сканы в чат |
