## Digital Pipeline — настроить в UI (один раз)

**Где:** [Сделки](https://proverkastaza.amocrm.ru/leads/pipeline/11140950/) → **Настроить** → воронка **«Проверка стажа»** → ячейка под этапом → **Создать задачу**.

Для каждого триггера:

| Параметр | Значение |
|----------|----------|
| Событие | **При переходе в этап** |
| Срок | см. таблицу ниже |
| Ответственный | **Текущий ответственный** |
| Тип | **Связаться** |
| Текст | скопировать из `amocrm_print_task_templates.py --key …` |

| Этап (переход **в**) | Ключ | Срок |
|----------------------|------|------|
| Связались | `qualification` | 24 ч |
| Квалифицирован | `diag_offer` | 48 ч |

> **«Новый лид»** — задачу создаёт SFRFR; дублирующий триггер в DP **не** нужен.

После настройки: **Сохранить** сценарий Digital Pipeline.

## Ручная постановка задачи (шаблон)

При создании задачи в карточке: **Тип «Связаться»** → вставить текст из скрипта или из чеклиста в задаче.

Шпаргалка на одну страницу: [assets/playbook-operator-new-lead-cheatsheet.pdf](assets/playbook-operator-new-lead-cheatsheet.pdf)

## Проверка

1. Тестовая сделка на «Новый лид» → есть задача «Чеклист: первый контакт».
2. Перенос в «Связались» → (если настроен DP) задача квалификации.
3. Тексты без СНИЛС / без вложений.
