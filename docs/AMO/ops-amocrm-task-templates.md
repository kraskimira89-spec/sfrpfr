**Где:** [Сделки](https://proverkastaza.amocrm.ru/leads/pipeline/11140950/) → **Настроить** → воронка **«Проверка стажа»** → ячейка под этапом → **Создать задачу**.

Для каждого триггера:

| Параметр | Значение |
|----------|----------|
| Событие | **При переходе в этап** |
| Срок | см. таблицу ниже |
| Ответственный | **Текущий ответственный** |
| Тип | **Связаться** |
| Текст | скопировать из `amocrm_print_task_templates.py --key …` |

| Этап (переход **в**) | Ключ | Срок |
|----------------------|------|------|
| Связались | `qualification` | 24 ч |

После настройки: **Сохранить** сценарий Digital Pipeline.

## Ручная задача: чек-лист ИЛС (self-service)

После отправки [`ils-self-check-checklist.md`](../../scripts/assets/copy/ils-self-check-checklist.md):  
Канон молчания: [playbook-sales-clarity-funnel.md](../marketing-sales/playbook-sales-clarity-funnel.md) **§5в**.

| Поле | Значение |
|------|----------|
| Тег / заметка | `self-service-checklist` · «Чек-лист ИЛС отправлен» · **Ожидаем ИЛС** (не LOSS) |
| Задача 1 | На **6-й** день: черновик напоминания №1 → сотрудник подтверждает отправку |
| Задача 2 | Ещё ~7 дней: черновик финала №2 (12–14 дн. от чек-листа) |
| После №2 без ответа | Архив / можно вернуться; авто-напоминания снять |
| Ответ клиента | Снять задачи; статус «В работе» |
| Не беспокоить | Не слать даже сервисные касания |

### Шаблон заметки (копировать в карточку)

```text
Чек-лист отправлен: [дата время]
Напоминание №1: [дата] / отправлено | не отправлено
Напоминание №2: [дата] / отправлено | не отправлено
Причина ожидания: ИЛС | трудовая | решение семьи | нет связи | другое
Следующий контакт: [дата]
Статус: ожидаем клиента | закрыто без сделки | архив
Не беспокоить: да | нет
```

Тексты касаний — в `ils-self-check-checklist.md` и clarity-funnel §5в.  
Не ставить задачу «дожать оплату» после отказа по цене. Не слать автоматом без просмотра.
