Оба плагина работают в навигационном слоте Яндекс Трекера. Функциональность проверена в тестовом режиме с использованием `weavix debug`; для плагина «Мастер задач SFRFR» подтверждено создание задач через интерфейс Трекера.

## 2. Что реализовано

### Мастер задач SFRFR

Плагин предназначен для быстрого и единообразного создания внутренних задач команды.

Реализовано:

- выбор очереди: `SFRFR`, `PUB`, `FUNNEL`;
- подсказки по назначению очередей;
- процессные теги, включая `publish-*`, `funnel-*` и опциональные теги для SFRFR;
- шаблоны заголовков и описаний задач;
- предупреждение при обнаружении признаков персональных данных: телефон, e-mail, СНИЛС;
- создание задачи и переход в созданную карточку;
- карточка плагина, описание, логотип, обложка и справочные материалы для каталога;
- отправка версии `0.1.6` на модерацию 23.08.2026.

Запрашиваемые права плагина ограничены чтением очередей, задач и тегов, а также созданием задач. Интерфейс использует уведомления и подтверждение действий.

### Качество STAZH

Плагин предназначен для регистрации внутренних задач качества и улучшения процессов в очереди `STAZH`.

Реализовано:

- создание задач только в очереди `STAZH`;
- выбор типа задачи, направления, источника, канала, повторяемости и приоритета;
- формирование тегов для дальнейшей аналитики;
- безопасное предварительное заполнение полей;
- усиленная защита от персональных данных: при обнаружении ПДн создание задачи блокируется;
- материалы для внутреннего каталога;
- отправка версии `0.1.1` на модерацию.

Плагин не предназначен для ведения клиентских дел. Клиентская информация и документы остаются в защищённом контуре административного кабинета `proverkastaza.ru`.

## 3. Ограничения по данным

В задачи Яндекс Трекера не передаются и не должны вручную вноситься:

- ФИО клиентов;
- телефоны и e-mail;
- СНИЛС, паспортные данные и адреса;
- выписки ИЛС;
- сканы и другие файлы клиентов;
- распознанный текст документов;
- содержание переписки с клиентами;
- ссылки, открывающие доступ к личному кабинету или документам.

В плагине «Мастер задач SFRFR» при обнаружении признаков ПДн выводится предупреждение. В плагине «Качество STAZH» создание задачи блокируется до удаления таких сведений.

## 6. Действия после модерации

Модерация и добавление в org выполнены **02.09.2026 17:20**. Для финальной приёмки:

1. Сотрудник включает плагины для себя в навигации Tracker (если ещё не включены).
2. Проверить рабочие сценарии:
   - создание задачи в очередях SFRFR, PUB и FUNNEL через «Мастер задач SFRFR»;
   - создание обезличенной задачи в STAZH через «Качество STAZH»;
   - проверка блокировки при попытке внести телефон, e-mail или СНИЛС в STAZH;
   - проверка, что созданная задача содержит ожидаемые теги, приоритет и шаблонные данные.
3. Опционально: `weavix debug` для локальной проверки.

Результаты приёмки — в отдельной задаче (не STAZH-1 prod smoke без явной проверки).

Работа может считаться полностью введённой в эксплуатацию, когда:

- обе версии одобрены платформой — **выполнено**;

- «Качество STAZH» создаёт задачи только в очереди STAZH — smoke;
- защита от ПДн срабатывает согласно заданному сценарию — smoke.
