# Как создать сообщество ВК «Проверка стажа»

**Дата:** 2026-08-25  
**Где:** лучше **компьютер**, [vk.com](https://vk.com) (в приложении часть пунктов короче).  
**Тексты** (описание, закреп, автоответ, посты): [copy-community-launch.md](copy-community-launch.md).  
**Официальная справка ВК (мастер меняется):** [создать и настроить сообщество](https://vk.com/@business-soobschestvo-vkontakte-instrukciya-po-sozdaniu-i-nastroike).

Сообщество создаёт **владелец воронки** вручную. API и автопубликация не используются. Paid / лид-форма / VK Реклама — **не включать** (BLOCKED).

Подписи пунктов в UI ВК со временем плывут: ориентируйтесь на **смысл** колонки «Параметр», не на дословное совпадение.

Личный мобильный владельца, ops и «домашний» номер в карточку сообщества **не ставить**.

## 2. Какие возможности включать

Смысл: ВК — витрина и перевод в MAX. Документы, оплату внутри ВК и «магазин» не подключаем.

| Возможность | Старт | Зачем так |
|-------------|-------|-----------|
| Тип / бизнес-инструменты | **Вкл.** | Контакты, кнопка, позже реклама |
| Открытое сообщество | **Вкл.** | Иначе нет охвата |
| Стена (записи сообщества) | **Вкл.**, пишет только администратор | Посты ведём мы |
| Предложить новость / стена участников | **Выкл.** | Иначе сканы и «проверьте мою трудовую» |
| Комментарии | **Вкл.**, модерация если есть | Отвечаем шаблоном «без сканов → MAX» |
| Сообщения сообщества | **Вкл.** | Только чтобы отдать автоответ в MAX |
| Приветствие в сообщениях | **Вкл.** | Текст из copy §5 |
| Вложения / файлы в ЛС | **Выкл.**, если тумблер есть | Иначе пришлют ИЛС и паспорт |
| Статус «онлайн» сообщества | **Выкл.** по умолчанию | Не изображать круглосуточную линию |
| Чаты сообщества (беседа подписчиков) | **Выкл.** | Там опять документы |
| Кнопка действия в шапке | **Вкл.** → ссылка MAX | Primary CTA |
| Магазин / товары ВК | **Выкл.** | Не продаём внутри ВК |
| Каталог услуг ВК | **Не заполнять** на старте | Оплата и заявка — сайт / MAX / кабинет |
| Онлайн-запись (YCLIENTS и аналоги) | **Выкл.** | Нет записи «в офис» |
| Донаты / VK Pay в сообществе | **Выкл.** | Оплата только канон сайта/кабинета |
| Приложения сообщества, квизы, мини-приложения | **Выкл.** | Лишние формы и ПДн |
| VK Реклама, продвижение, лид-форма | **Выкл.** | Paid = BLOCKED |
| Обсуждения | **Выкл.** или только админ | Не место для ИЛС |
| Возрастное ограничение 18+ | **Не ставить** | Родственники 30–50 тоже аудитория |
| Гео «только Ноябрьск / ЯНАО» | **Не ограничивать** | Работаем дистанционно по России |

Отзывы у бизнес-сообщества ВК часто включены сами. Фейковые не заказывать. Если человек приложит скан к отзыву — скрыть/пожаловаться и ответить: документы только в кабинете.

## 4. Пошагово в UI

### Шаг 0. Аккаунт

1. Откройте **vk.com** с компьютера.  
2. Войдите **аккаунтом владельца воронки** (страница, с которой потом будет кабинет рекламы ООО).  
3. Не создавайте сообщество с личного профиля сотрудника.

### Шаг 1. Мастер «Создать сообщество»

1. Левое меню → **Сообщества** → **Создать сообщество**.  
   В приложении: **Сообщества** → **+**.  
2. Если спрашивают тип: **Бизнес**.  
3. Название: `Проверка стажа`.  
4. Тематика: услуги / консультации.  
5. Тумблер **«Бизнес-инструменты»** — **включить** (товары и услуги внутри ВК потом не заполняем).  
6. Нажать **Создать сообщество**.  
7. Если ВК пришлёт SMS — код с **номера аккаунта**, не меняйте из‑за этого публичный +7 909 195-04-08.

### Шаг 2. Сразу после «сообщество создано»

1. Если мастер предлагает контакты — заполните публичный телефон **+7 909 195-04-08**, сайт из таблицы §3, почту `info@proverkastaza.ru`. Иначе «Завершить» и заполнить в **Управление**.  
2. Не приглашать друзей пакетом и не включать «продвигать сообщество».  
3. Скопировать URL (`vk.com/club…` или уже короткий) — вписать в [playbook-vk-community.md](playbook-vk-community.md) §1. Пока не выдумывать адрес.

### Шаг 3. Управление → информация

Путь: сообщество → **Управление** → информация / настройки (названия вкладок у ВК разные).

1. Короткий адрес: `proverkastaza` или ближайший свободный.  
2. Статус — copy §2.  
3. Описание — copy §3.  
4. Сайт, телефон **+7 909 195-04-08**, email, юр. адрес, пометка «дистанционно по России».  
5. Аватар и обложка — §3 и copy §1.2.  
6. Сохранить.

### Шаг 4. Кнопка действия

**Управление** → **Кнопка действия**.

1. Включить.  
2. Действие: **открыть ссылку / сайт / перейти** (не «позвонить», не «написать сообществу» как главное).  
3. URL: `https://max.ru/id8905998693_1_bot`.  
4. Текст кнопки, если можно задать: **Уточнить ситуацию в MAX**.  
5. Сохранить.

Телефон для звонка остаётся в карточке контактов, не в главной кнопке.

### Шаг 5. Сообщения

**Управление** → **Сообщения** (или раздел «Сообщения» в сообществе).

1. Сообщения сообщества — **вкл.**  
2. Кто может писать — все (иначе кнопку MAX всё равно дублируем, но часть людей нажмёт «Написать»).  
3. Приветствие — **вкл.**, вставить copy §5.  
4. Файлы / вложения — **выкл.**, если есть тумблер.  
5. Боты, автоворонки ВК, квизы — **не подключать**.  
6. «Онлайн сообщества» — выкл., пока нет живого дежурства.  
7. Написать самому себе с другого аккаунта: должен прийти автоответ, **без** возможности спокойно прикрепить скан.

### Шаг 6. Стена, комментарии, разделы

1. Кто может постить на стену — **только сообщество / администраторы**.  
2. Предложить новость — **выкл.**  
3. Комментарии — вкл.; премодерация — если есть.  
4. Обсуждения, чаты, магазин, услуги, запись, донаты, приложения — **выкл. / не создавать**.  
5. Раздел «Товары» не наполнять.

### Шаг 7. Люди

1. **Управление** → руководители / администраторы → добавить **ops** администратором.  
2. Владельца не передавать на личную страницу сотрудника.

### Шаг 8. Тексты (когда решите запуск)

Не обязательно в тот же день, что создание.

1. Черновики: закреп и посты 1–3 — copy §4 и §6.  
2. Публиковать и закреплять — только по решению владельца.  
3. Ads, продвижение, лид-форма — не трогать.
