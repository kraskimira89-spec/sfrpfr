# Как создать сообщество ВК «Проверка стажа»

**Дата:** 2026-08-25  
**Где:** лучше **компьютер**, [vk.com](https://vk.com) (в приложении часть пунктов короче).  
**Тексты** (описание, закреп, автоответ, посты): [copy-community-launch.md](copy-community-launch.md).  
**Официальная справка ВК (мастер меняется):** [создать и настроить сообщество](https://vk.com/@business-soobschestvo-vkontakte-instrukciya-po-sozdaniu-i-nastroike).

Сообщество создаёт **владелец воронки** вручную. API и автопубликация не используются. Paid / лид-форма / VK Реклама — **не включать** (BLOCKED).

**Решение владельца (2026-08-25):** новый аккаунт ВК **не** регистрируем. Сообщество создаём с **основной личной страницы**, которая уже на публичном номере **+7 909 195-04-08**. Второй телефон — не для нового ВК и не в карточку сообщества. Второй админ — только другой доверенный человек, не «клон» той же страницы.

Подписи пунктов в UI ВК со временем плывут: ориентируйтесь на **смысл** колонки «Параметр», не на дословное совпадение.

## 4. Пошагово в UI

### Шаг 0. Аккаунт

1. Откройте **vk.com** с компьютера.
2. Войдите **основной личной страницей**, которая уже на **+7 909 195-04-08**. Новый аккаунт не создавайте.
3. Не переключайтесь на другой свой ВК (второй телефон) «для чистоты» — сообщество должно висеть на этой странице.

### Шаг 1. Мастер «Создать сообщество»

1. Левое меню → **Сообщества** → **Создать сообщество**.
  В приложении: **Сообщества** → **+**.
2. Если спрашивают тип: **Бизнес**.
3. Название: `Проверка стажа`.
4. Тематика: услуги / консультации.
5. Тумблер **«Бизнес-инструменты»** — **включить** (товары и услуги внутри ВК потом не заполняем).
6. Нажать **Создать сообщество**.
7. Если ВК пришлёт SMS — код с **+7 909 195-04-08**. Публичный телефон в карточке тот же.

### Шаг 2. Сразу после «сообщество создано»

1. Если мастер предлагает контакты — заполните публичный телефон **+7 909 195-04-08**, сайт из таблицы §3, почту `proverkastaza@yandex.ru`. Иначе «Завершить» и заполнить в **Управление**.
2. Не приглашать друзей пакетом и не включать «продвигать сообщество».
3. URL: [https://vk.ru/proverkastaza](https://vk.ru/proverkastaza) (короткий адрес занят; id `241062531`).

### Шаг 3. Управление → информация

Путь: сообщество → **Управление** → информация / настройки (названия вкладок у ВК разные).

1. Короткий адрес уже занят: `proverkastaza`.
2. Статус — copy §2.
3. Описание — copy §3.
4. Сайт, телефон **+7 909 195-04-08**, почта `proverkastaza@yandex.ru`, юр. адрес, пометка «дистанционно по России». В карточке ВК **не** ставить `info@proverkastaza.ru` и второй телефон.
5. Аватар: `assets/sfrfr-logo-transparent-500.png`. Обложка: `**assets/vk-community-cover-1920x768.png**` (не zip-шаблон: он 911×364, ВК требует ≥960×384).
6. Сохранить.

### Шаг 4. Кнопка действия

**Факт платформы (техподдержка ВК, 2026-08-26):** название кнопки шапки **не меняется**. У нас остаётся **«Сообщение»**. Не тратить время на «открыть ссылку» / свой текст «Уточнить ситуацию в MAX».

Что вместо этого:

1. Кнопка **«Сообщение»** — нормально: человек пишет сообществу.
2. Сразу срабатывает **приветствие** (шаг 5) со ссылкой MAX.
3. В закрепе и описании — та же ссылка MAX и телефон.
4. **Не** ставить главной «Позвонить».

Телефон остаётся в карточке контактов.

### Шаг 5. Автоответ «без сканов»

Нужны **два** места: приветствие и запрет файлов. Подписи у ВК плывут — ищите смысл.

**Путь A (чаще с компьютера):** сообщество → справа **Управление** → **Сообщения**.

**Путь B:** на странице сообщества вкладка **Сообщения** (не личные) → шестерёнка **Настройки**.

1. Сообщения сообщества — **включены**. Кто может писать — **все**.
2. Найти блок **Приветствие** / **Приветственное сообщение** / **Сообщение при первом обращении** — **включить**.
3. Вставить текст из [copy-community-launch.md](copy-community-launch.md) §5 целиком. Сохранить.
4. Найти **вложения / файлы / документы / фото в сообщениях** — **выключить**. Если тумблера нет: в приветствии уже сказано не присылать сканы; тогда при модерации удалять вложения вручную.
5. Не подключать ботов, квизы, VK-автоворонки. **Работа с API** не трогать.
6. «Онлайн сообщества» — выкл., пока нет живого дежурства.
7. Проверка: с **другой** страницы ВК написать сообществу. Должен прийти текст про MAX. Кнопки скрепки / файла быть не должно (или её нельзя нажать).

Это и есть «автоответ без сканов стоит». Callback/Long Poll для этого **не** нужны.

### Шаг 6. Стена, комментарии, разделы

1. Кто может постить на стену — **только сообщество / администраторы**.
2. Предложить новость — **выкл.**
3. Комментарии — вкл.; премодерация — если есть.
4. Открыть **Управление → Разделы** и выставить по таблице ниже.
5. Приложения, запись, донаты — не создавать.

#### Карточки «Услуги» (канон названий)

Не писать «под ключ». Кнопка карточки — сайт `/tarify/` или MAX, **не** «оплатить во ВК».

**Факт платформы (техподдержка ВК, 2026-08-26):** порядок трёх карточек на главной **не меняется**. Виджет показывает **8 000 → 5 000 → 3 000** (сначала дороже). Не пересоздавать услуги ради порядка.

| Шаг воронки | Название в ВК | Цена |
|-------------|---------------|------|
| 1 | Диагностика стажа | 3 000 ₽ |
| 2 | Подготовка документов | 5 000 ₽ |
| 3 | Сопровождение до подачи | 8 000 ₽ |

Порядок шагов для человека — в **закрепе, описании и автоответе**, не в ряду плиток. Префиксы `1.` / `2.` / `3.` в названиях — по желанию, не обязательно.

В тексте карточки: можно остановиться после шага; подаёте вы сами; решение СФР. Word 100 ₽/разворот — не отдельной услугой ВК.

### Шаг 7. Люди

1. Создатель (эта страница) остаётся владельцем сообщества.
2. Второго админа добавлять **только** если это другой доверенный человек (не второй ваш аккаунт на другом телефоне). Пока одного админа достаточно.

### Шаг 8. Тексты (когда решите запуск)

Не обязательно в тот же день, что создание.

1. Черновики: закреп и посты 1–3 — copy §4 и §6.
2. Публиковать и закреплять — только по решению владельца.
3. Ads, продвижение, лид-форма — не трогать.
