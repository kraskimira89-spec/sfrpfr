# 2026-10-21 — Word «ТК» → трудовая; settle без ложного «разбора»

## Причина (тестовое дело)

- **Корневой баг:** `set_document_type` импортировал несуществующий
  `sfrfr.db.supabase_client` → тип **никогда** не писался в БД (`doc_type=null`).
- Дополнительно: эвристика имени не знала токен «ТК».
- Settle строил комплект по null → «другой документ» + снова «пришлите трудовую».
- Текст «Первичный разбор готов» обещал анализ без задачи.

## Исправление

1. Имя: токен `ТК`; DOCX: title/headers/tables + magic PK→docx.
2. Классификация синхронно при приёме; preview в БД; при ошибке — `other`.
3. Перед settle — `reclassify_case_untyped`; без повторной отправки того же текста.
4. Честные формулировки комплекта; при полученной трудовой не просить её снова.
5. `tools/reclassify_case_docs.py` — пересчёт уже лежащих файлов на VPS.

## Ограничение

Старый `.doc` (OLE) не парсим — нужен `.docx` или PDF.
