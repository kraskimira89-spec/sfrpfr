# 2026-08-08 — чередование фонов секций на главной

## Проблема

Соседние блоки с одним классом `sfrfr-section--alt` (или без фона) визуально сливались: «Как пользоваться MAX» / hero, «Полезные статьи» / «Частые вопросы», «Что проверяем» / «Кто оказывает».

## Решение

- В `sfrfr-home.html` выставлены чередующиеся `--alt` / без `--alt`.
- В CSS: базовый фон секции `--sfrfr-band` (#e8eef5), `--alt` — белый.
