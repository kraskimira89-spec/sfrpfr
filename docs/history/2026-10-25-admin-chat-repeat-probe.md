## Что проверить на данных (read-only)

Номер `ПС-937196` в UI = последние 5 hex UUID → int (`937196` → `e4cec`).

На supabase2 (MCP, 2026-10-25) совпадения `right(replace(id,'-',''),5)='e4cec'` **не найдено** —
зонд на этой БД не подтвердил дело; повторить на том же контуре, с которого снят скриншот admin.

```sql
SELECT id FROM cases WHERE right(replace(id::text,'-',''),5) = 'e4cec';

SELECT md5(trim(body)) AS dig, left(trim(body),80) AS head, count(*) AS n
FROM case_messages
WHERE case_id = '<uuid>'
GROUP BY 1, 2
HAVING count(*) > 1
ORDER BY n DESC;
```

Сверить с `case_chat_outbox` / логами MAX delivery — уходил ли каждый ряд клиенту.
