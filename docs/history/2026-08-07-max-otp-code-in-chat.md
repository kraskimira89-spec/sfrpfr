# 2026-08-07 — вход клиента: код в MAX → ввод в кабинете

## Что изменили

- Клиентский вход без телефона больше не показывает pair-code «отправьте в MAX».
- Бот `/login` и кнопка «Получить код для входа» присылают 6-значный код и ссылку
  `cabinet/?mode=login&channel=max&verify_ticket=…`.
- Кабинет: поле «Код из MAX», poll `code_sent` / `verify_ticket`, ввод кода как у email OTP.
- Staff-вход по pair-code без изменений в этой задаче.

## Критерий

Клиент видит код только в личном чате MAX и вводит его на странице входа кабинета.
