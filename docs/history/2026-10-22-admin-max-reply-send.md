# 2026-10-22 — «Отправить в MAX» в чате специалиста

## Симптом

Кнопка «Отправить в MAX» в правой панели чата дела казалась мёртвой (пустой клик / нет обратной связи).

## Причины

1. Авто/ручные подсказки DeepSeek ставили глобальный `busy`, из‑за чего кнопка отправки становилась `disabled` без пояснения.
2. `mirror_staff_message_to_max` глотал сбой доставки; API отвечал `ok: true`, хотя MAX не получил сообщение.
3. Ранний `return` в UI без `setNotice`.

## Фикс

- `suggestBusy` отдельно от `busy` отправки.
- `mirror_staff_message_to_max` → `bool`; при `False` endpoint `max-reply` отдаёт 502 `max_send_failed` с текстом для специалиста.
- Нормализация `clients` list/dict; человекочитаемые коды в admin.
