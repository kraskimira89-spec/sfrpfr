# 2026-08-08 — Правка JSON-LD по замечаниям валидатора

## Проблема
В аудиторе/валидаторе красные пометки: у Service нет offers, у Organization нет priceRange; лишнее поле `url` у ListItem.

## Что исправлено
- `Organization`: `priceRange`, адрес, телефон, brand «Проверка стажа».
- `Service` (главная / услуга / тарифы): реальные `Offer` 3000 / 10000 / 25000 ₽.
- `BreadcrumbList`: только `position` + `name` + `item` (без дубля `url`).
- `WebPage` со ссылкой на `#breadcrumbs`.
- Без фейковых `aggregateRating` / `review` (нужны реальные отзывы).

## Не делать
Не собирать одну «цепочку» из всех пунктов меню — это ошибка генераторов, на сайте её нет.
