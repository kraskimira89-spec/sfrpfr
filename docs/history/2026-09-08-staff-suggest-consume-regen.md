# Кабинет сотрудника: подсказки после отправки в MAX

## Запрос

После выбора одной из трёх подсказок и отправки в MAX она должна исчезать из списка;
нужна кнопка «Перегенерировать», чтобы видеть следующие варианты.

## Решение

- `sendMaxReply` убирает отправленный/выбранный черновик из `replySuggestions`.
- В блоке черновиков: счётчик «осталось N» + кнопка «Перегенерировать».
- Нижняя кнопка переименовывается в «Перегенерировать подсказки», пока есть чипы.

Файлы: `case-chat-panel.tsx`, `admin-cabinet.tsx`, `globals.css`.
