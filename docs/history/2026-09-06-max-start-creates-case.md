# 2026-09-06 — дело сразу по «Начать» в личном боте MAX

## Зачем

Письмо сотруднику приходило раньше, чем в базе появлялось дело. Ссылка `?case=` открывала пустую страницу / «дело не найдено», переписки не было.

## Как должно работать

1. Клиент в личном боте нажимает «Начать».
2. Сразу создаётся дело в реестре, `max_user_id` привязан, welcome и кнопки пишутся в ленту.
3. Письмо и кнопка в ops уходят **после** создания дела.
4. Ссылка: `admin/c/{id}?view=cases&focus=chat` → реестр → карточка → чат.
5. Сотрудник и бот могут писать клиенту на любом этапе.

## Код

- `handler._handle_bot_start` + `_notify_staff_max_started`
- таймаут создания дела 15 с, фоновый повтор если webhook не успел
- admin deep-link: localStorage, сначала реестр, один retry
