# 2026-08-10 — выпадающие меню и шапка

## Что было
- Выпадающие меню: синий/зеленоватый фон, силуэт справа.
- После правок шапка «разъезжалась»: бренд сжимался в столбик букв (zoom ~125%).

## Что сделали
- Единый стиль dropdown: белая панель, левый контур, hover без зеленоватого фона, зелёная черта справа.
- Бренд `flex-shrink: 0` + `white-space: nowrap`; меню может wrap; submenu `position: absolute`.
- Полная пересборка WP-меню на каждый деплой отключена (`SFRFR_REBUILD_MENU=1` для force).

## Проверка
- Playwright: `crushed=false` на desktop и zoom 125%; маркеры `sfrfr-header-layout-v1`, `sfrfr-nav-dropdown-v3`.
