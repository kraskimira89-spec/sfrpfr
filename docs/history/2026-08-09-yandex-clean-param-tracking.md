# 2026-08-09 — Clean-param для рекламных меток

## Запрос

Добавить в `robots.txt` правило Яндекса, которое не считает адреса с рекламными
GET-параметрами отдельными страницами, и развернуть правило на сайте.

## Выполнено

- MU-плагин `sfrfr-seo-robots.php` дополнен отдельной директивой `Clean-param`;
- учтены UTM-метки, идентификаторы переходов Яндекса, Google, VK, Meta и myTarget,
  метки интернет-рекламы и внутренние коды рекомендаций и кампаний;
- сохранена ранее действовавшая директива для параметров с ПДн;
- проверка наличия блока привязана к маркеру SFRFR, поэтому сторонняя директива
  `Clean-param` больше не мешает добавить правила проекта;
- рабочая инструкция Яндекс Вебмастера актуализирована.

## Развёртывание

Изменение доставляется на WordPress через `scripts/vps_deploy.sh`, который
запускает `scripts/wp_deploy_metrika.sh` и копирует MU-плагин на сайт.
