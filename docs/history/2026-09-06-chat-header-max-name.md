# 2026-09-06 — имя из MAX в шапке чата сотрудника

Бот писал «Здравствуйте, Владимир!», а шапка кабинета — «ФИО не указано»:
в `clients.full_name` оставалась заглушка `MAX {user_id}`.

- Имя из webhook MAX пишется в профиль, если там ещё заглушка.
- Шапка чата берёт то же обращение из приветствия бота, если ФИО в карточке нет.
