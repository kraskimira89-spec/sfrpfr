# MAX bot_owned funnel: документы → оплата → расхождения → план

## Цель

Собрать единую воронку в личном чате MAX (единый `case_id` с кабинетом):

CTA сайта → FSM / LLM → дело → согласие / документы / оплата в чате или кабинете →
бот принимает файлы → комплект или дозапрос → счёт → оплата / чек → подтверждение →
пункты расхождений или ещё документы → согласование плана со специалистом.

## Сделано

1. Сервис `src/sfrfr/services/max_bot_funnel.py`:
   - nudge согласия перед DIAG, если комплект готов;
   - после оплаты — следующий шаг сверки + staff task;
   - после `audited` / snapshot findings — пункты расхождений в MAX;
   - кнопка «Согласовать план со специалистом» (`funnel:agree_plan`).
2. Хуки: `max_bot_invoice` (consent), `finance_automation.on_order_fully_paid`,
   `CaseRepository.save_pipeline_snapshot` / `update_case_status(audited)`,
   callback в `handler.py`.
3. Текст комплекта (`max_kit_status`) поясняет путь после оплаты.
4. Тесты: `tests/unit/test_max_bot_funnel.py`.

## Границы

- Полный разбор расхождений клиенту — после оплаты DIAG (не бесплатная замена диагностики).
- Деньги и счета — код, не LLM.
- Подачу в СФР клиент делает сам; решение принимает СФР.
