# Playbook: подготовка комплекта для архивного запроса

**Дата:** 2026-08-23  
**Статус:** канон продаж / ops после PDF

## 1. Название услуги

**Корректно:** подготовка комплекта для архивного запроса по подтверждению периода работы.

**Неверно:** «мы найдём архив», «восстановим стаж», «гарантируем включение периода».

Клиент покупает **понятный маршрут и готовые документы для самостоятельной подачи**, а не результат архива или СФР.

Социально-правовые справки архивы выдают бесплатно при наличии документов; сервис готовит комплект запроса, а не «покупку справки».

---

## 2. Цена (публичный канон)

Опубликовано только **3 000 / 5 000 / 8 000 ₽**. Не использовать в чатах и на сайте **10 000**, **25 000**, «под ключ».

| Объём | Публичный тариф | Когда |
|-------|-----------------|--------|
| Один период, один запрос, до 2 предполагаемых адресатов, проект + перечень + инструкция | **Подготовка документов — 5 000 ₽** | Типовой архивный кейс после диагностики |
| Несколько периодов / адресатов + проект обращения в СФР после ответа | **Сопровождение до подачи — 8 000 ₽** или смета по этапам | Сложный / расширенный объём |
| Только объяснить PDF, без комплекта | Не продавать | Ответ «2» / «3» на навигацию |

Публичный мини-тариф «от 4 000 ₽» **не использовать**. Канон: один комплект — **5 000**; доп. период / доп. адресат / расширение до проекта в СФР — **8 000** (сопровождение до подачи) или смета.

Перед ценой всегда: «Хотите, опишу состав работ и стоимость?»

## 3. Что входит / не входит

### Входит

1. Карточка спорного периода (даты, организация, должность, населённый пункт, источник сведений).  
2. Проверка исходных документов и пробелов.  
3. Возможные адресаты: организация, правопреемник, ведомственный / муниципальный / региональный архив (**«предполагаемый»**, не «точно там»).  
4. Проект запроса.  
5. Перечень приложений.  
6. Инструкция: как направить самостоятельно и что делать после ответа.  
7. При тарифе 8 000 — при необходимости проект обращения в СФР **после** ответа архива.

### Не входит

- гарантия нахождения документов;  
- запрос от имени клиента без отдельного основания / полномочий;  
- получение ответа архива вместо клиента;  
- решение СФР / перерасчёт;  
- судебное представительство.

---

## 4. Когда предлагать

Только если:

- диагностика выдана и проверена;  
- клиент понял PDF (навигация 1/2/3 закрыта или вопрос по документу снят);  
- в PDF есть конкретный период, требующий подтверждения;  
- есть база для запроса (хотя бы трудовая / иные сведения о месте и времени).

Не предлагать при стрессе «только объясните документ», гарантии пенсии, суде, неизвестном объёме.

---

## 5. Вопросы до цены

### Период

- Точные даты в трудовой?  
- Название организации **в тот период**?  
- Город / район / область?  
- Должность / профессия?  
- Переименования, реорганизация?  
- Номер приказа, печать, запись об увольнении?

### Документы

- Трудовая или читаемые сканы?  
- Договор, справки, расчётные, приказы, лицевые счета?  
- Ответ СФР с указанием неучтённого периода?  
- Уже был ответ архива / работодателя?  
- Смена ФИО + подтверждающий документ?

### Маршрут

- Правопреемник известен?  
- Регион регистрации и место работы?  
- Ведомство / отрасль / вышестоящая организация?  
- Клиент может сам подписать и подать?  
- Родственник: есть ли законное основание и полномочия?

## 6. Статусы в карточке (amo / заметка)

```text
Диагностика готова
→ Сведения о периоде собраны
→ Маршрут поиска согласован
→ Проект запроса подготовлен
→ Проверка клиентом
→ Комплект выдан
→ Ожидаем ответ архива
→ Ответ получен
→ Нужен следующий шаг / закрыто
```

### Поля

```text
Период: дата начала — дата окончания
Организация: историческое название
Населённый пункт / регион
Должность
Источник сведений: трудовая / договор / справка / клиент
Правопреемник: известен / неизвестен / проверить
Архив: предполагаемый / подтверждённый
Нужные приложения
Дата проекта запроса
Дата выдачи комплекта
Дата самостоятельной подачи клиентом
Контрольная дата ответа
Тариф: 5 000 (подготовка) | 8 000 (до подачи)
```

ПДн и сканы — только кабинет, не MAX.

## 7. Состав пакета клиенту

### Карточка периода

```text
Период: ДД.ММ.ГГГГ–ДД.ММ.ГГГГ
Организация: [историческое название по трудовой]
Должность: […]
Место работы: [населённый пункт, регион]
Проблема: период не отражён в предоставленной выписке ИЛС / требует подтверждения
Имеющиеся подтверждения: трудовая, стр. …
```

### Карта маршрута

```text
1. Проверить, действует ли организация или есть правопреемник.
2. Если нет — социально-правовой запрос в архив по месту хранения документов организации.
3. При необходимости — повторный запрос по уточнённым данным.
4. Ответ приложить к обращению в СФР.
```

### Проект запроса

Шаблон — в [`archive-request-offer.md`](../../scripts/assets/copy/archive-request-offer.md).  
Клиент сам заполняет контакты, дату, подпись. Не оставлять вымышленные реквизиты.

### Инструкция по подаче

```text
1. Проверить адресат и способ подачи на официальном сайте архива/организации.
2. Заполнить контакты, дату, подпись.
3. Приложить копии по перечню.
4. Сохранить копию запроса и подтверждение отправки.
5. Ответ загрузить в защищённый кабинет.
6. Не отправлять трудовую, СНИЛС, архивную справку в открытый чат.
```

## 8. После выдачи комплекта

Через **10–14 дней** (сервисный черновик → сотрудник):

```text
Здравствуйте! Получилось ли направить запрос?
Если отправили — сохраните подтверждение подачи.
Когда придёт ответ, загрузите его в защищённый кабинет —
посмотрим, какой следующий шаг нужен для обращения в СФР.
```

Не просить переслать ответ или сканы в MAX.

## 9. Самопроверка оператора

- [ ] Название услуги без «найдём / восстановим»  
- [ ] Цена 5 000 или 8 000 по объёму, не «от 4 000» публично  
- [ ] Два пути: сам / с нами  
- [ ] «Может понадобиться», не «СФР обязан»  
- [ ] Не входит: гарантия архива, подача от имени, суд  
- [ ] Подача — клиент; решение — СФР
