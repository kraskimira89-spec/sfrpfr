## Главный принцип

PDF для пенсионеров и родственников верстать прежде всего **под печать и чтение на экране без увеличения**: крупный шрифт, одна колонка, короткие блоки, высокий контраст и много воздуха.

> Если макет красив только при масштабе 150–200%, он **не готов**.

Практический ориентир: минимум **12 pt**, комфортнее **14 pt** основного текста.

---

## Базовые параметры (A4)

| Элемент | Рекомендация |
|---|---:|
| Формат | A4, вертикальный, 210 × 297 мм |
| Поля | **18–22 мм** со всех сторон |
| Рабочая ширина текста | 165–170 мм |
| Основной текст | **14 pt**, минимум 13 pt |
| Подписи и пояснения | 12 pt, не меньше |
| H1 | 30–34 pt |
| H2 | 20–24 pt |
| H3 | 16–18 pt |
| Текст таблиц | 12–13 pt |
| Межстрочный интервал | 1,35–1,5 |
| Интервал между абзацами | 8–12 pt |
| Длина строки | 45–70 знаков |
| Отступ до нового блока | 16–24 pt |
| Высота строк с чекбоксами | Не менее 10–12 мм |
| Размер чекбокса | 5–6 мм для печати |

## Одна колонка

Не делайте газетную вёрстку в две–три колонки.

Плохо: две длинные колонки рядом.  
Хорошо: заголовок → нумерованные шаги → чекбокс → поле даты.

Одна колонка помогает не терять строку и комфортно печатать.

---

## Типографика

### Шрифты

Один основной, максимум два.

Подходят: `PT Sans`, Arial, Noto Sans, Source Sans 3, Inter, Roboto, Verdana.  
Для печати безопаснее: **PT Sans**, Arial, Noto Sans.

Не использовать: рукописные; `Light`/`Thin`; `Condensed`; капс для абзацев; курсив для длинного текста; больше двух гарнитур.

### Иерархия

```text
H1: 32 pt / Bold
H2: 22 pt / SemiBold
H3: 17 pt / SemiBold
Основной текст: 14 pt / Regular
Подпись: 12 pt / Regular
```

Не уменьшайте шрифт, чтобы «всё влезло». Лучше добавить страницу.

---

## Контраст и цвет

Обычный текст ≥ **4,5:1**, крупный ≥ **3:1**.

```text
Основной текст: #1F2933
Основной фон: #FFFFFF
Тёмно-синий заголовок: #1B486C
Зелёный акцент: #1D6B4A
Янтарное предупреждение: #7A4D00
Светлый фон карточки: #EFF6FB
Граница карточки: #B7C6D2
```

Правила:

- нет текста на фото, градиентах, текстурах;
- нет бледно-серого для важного;
- смысл не только красным/зелёным — иконка + подпись («Нужно уточнить», «Подтверждено»);
- подчёркивание — только у кликабельных ссылок.

---

## Карточки и таблицы

### Карточка «Шаг»

- белый или очень светлый фон;
- граница не светлее `#B7C6D2`;
- цветная вертикальная линия слева **4–6 px**;
- внутренний отступ **12–16 мм**;
- не более **3–5** строк действия в карточке.

### Таблицы

Максимум **3–4** колонки. Шире — разбить или вынести.

Для лид-магнита предпочтительны **заполняемые карточки**, а не широкие таблицы (см. карточку спорного периода в исходнике текста).

---

## Ритм одной страницы

```text
1 крупный заголовок
1 короткое объяснение — до 3 строк
1 карточка или 3–5 шагов
1 действие с чекбоксом / полем
1 небольшой инфоблок или предупреждение
```

Не совмещать на одной странице инструкцию + таблицу + кейс + три CTA + юридический текст.

### Скелет страницы

```text
Логотип · Папка пенсионных документов     (12 pt)
─────────────────────────────────────────
Шаг 3. …                                  (22 pt)
Короткое объяснение                       (14 pt)
□ … □ … □ …                               (14–16 pt)
┌ Важно … ┐
proverkastaza.ru                   N из 8 (11–12 pt)
```

## Экспорт

### Canva

1. Документ **A4**, не «Презентация».
2. Не превращать текст в картинку.
3. Два файла: `PDF для печати` + `PDF standard`.
4. Проверить на телефоне при **100%**.
5. Распечатать одну страницу на обычном принтере.
6. По возможности — кликабельные ссылки и закладки.

### Word / PowerPoint

1. Стили Заголовок 1 / 2 / основной.
2. Не макетировать пробелами и табами.
3. «Сохранить как PDF», не скриншоты.
4. Текст в PDF должен выделяться и копироваться.

### Adobe Acrobat Pro (если есть)

- порядок чтения;
- теги заголовков;
- кликабельные ссылки;
- title + язык `ru`;
- закладки;
- Accessibility Check.

## Четыре теста «без увеличения»

### 1. Телефон (100%)

```text
□ Абзац читается без pinch-to-zoom
□ Нет горизонтальной прокрутки строки
□ Различаются чекбоксы и предупреждения
□ Ссылка / QR доступны
```

### 2. Ноутбук (100%)

```text
□ Читается с обычного расстояния
□ Карточки не сливаются
□ Не нужно искать продолжение шага
```

### 3. Ч/б печать

```text
□ Видны границы карточек
□ Статусы отличаются без цвета
□ Можно отметить ручкой
□ Текст не обрезан по краям
```

### 4. Человек 60+ без подсказок

```text
1. Найти, как получить ИЛС
2. Отметить один пункт чек-листа
3. Заполнить карточку спорного периода
4. Понять следующий шаг
```

«А куда нажать?» / «Что это значит?» → править макет, не пользователя.

## Чек-лист перед публикацией

```text
□ A4, одна колонка, поля от 18 мм.
□ Основной текст 14 pt, подписи от 12 pt.
□ Не более двух шрифтов.
□ Контраст текста от 4,5:1.
□ Нет текста на фотографиях и градиентах.
□ Каждая страница — одна основная мысль.
□ Таблицы не шире четырёх колонок.
□ Карточки можно заполнить ручкой.
□ Ссылки и QR проверены.
□ Текст PDF выделяется и копируется.
□ Есть заголовки и корректный порядок чтения.
□ Проверено на телефоне, ноутбуке и в печати.
□ Финальный CTA понятный, без давления.
```
