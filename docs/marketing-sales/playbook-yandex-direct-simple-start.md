# Playbook: Простой старт в Яндекс Директе (SFRFR)

**Дата:** 2026-08-22  
**Статус:** готов к запуску после бюджета владельца  
**Источники:** письмо Яндекса; PDF в `Yandex Direct/`; [Справка Директа](https://yandex.ru/support/direct/ru/products-automatic/create); [инструкция на direct.yandex.ru](https://direct.yandex.ru/base/articles/kak-zapustit-prostoj-start)

---

## Что это

**Простой старт** — автоматический режим Директа (в интерфейсе **Директ Про**):

1. Вы даёте **ссылку** и **кратко о бизнесе**.
2. Система **генерирует объявления**, подбирает **аудиторию** и **площадки** (Поиск + РСЯ + при необходимости Карты).
3. Алгоритм **перераспределяет бюджет** на объявления и каналы, которые дают больше целевых действий.

Подходит, если **мало времени** и **мало опыта** с ручными кампаниями. Не заменяет точечный поиск по семантике Wordstat — для теста «север × поиск» см. [research-test-noyabrsk-north-direct-2026-08.md](research-test-noyabrsk-north-direct-2026-08.md) (там **Мастер кампаний / поиск**, не Простой старт).

## Запуск (пошагово)

### 0. Подготовка

- Отдельный логин Директа (не личная почта) — [перенос кампаний на другой логин невозможен](https://direct.yandex.ru/base/articles/kak-zapustit-prostoj-start).
- Сайт: **`https://proverkastaza.ru`** (apex, без www).
- Счётчик Метрики **`111134477`** уже на сайте — в кампании должен **подтянуться автоматически**; если нет — «Повторить поиск счётчиков».
- Sprav **`82469923047`** — при создании кампании связать организацию или «Нет, продолжить без организации» (дистанционный сервис).

### 1. Создать кампанию

[Директ](https://direct.yandex.ru/) → **Добавить** → **Кампанию** → вкладка **Простой старт** → **Перейти к созданию**.

### 2. Ссылка

- **Сайт:** `https://proverkastaza.ru/` или сегментная посадочная (см. ниже).
- **Не** «Продолжить без сайта» — у нас готовый сайт и лендинги.
- Резервная посадочная (при нестабильном интернете): главная или `/kontakty/`.

### 3. Организация в Картах

- Юр. адрес Ноябрьск, работа **по всей России** — в анкете и на `/kontakty/` это указано.
- Если Sprav найден — **подтвердить**; для чистого веб-оффера можно **без организации**.

### 4. Регионы

| Цель | Регион |
|------|--------|
| Общий тест, лиды по РФ | **Россия** (бюджет выше) |
| Север (волна 1) | 7–8 субъектов из [плана](research-test-noyabrsk-north-direct-2026-08.md) — **узкий гео = меньший бюджет** |

### 5. «Чем вы занимаетесь»

Коротко, без лишних рубрик:

> Помогаем разобраться со стажем для пенсии: сверка трудовой книжки и выписки ИЛС, подготовка документов и плана. Дистанционно по России.

Не указывать «юристы», «госуслуги», «перерасчёт пенсии» как обещание результата.

### 6. Изображения

- 5–15 фото: логотип, эксперты (с согласием), скрины **без ПДн** клиентов.
- Размер от 450×450, JPG/PNG, до 10 МБ.
- Материалы: `scripts/assets/`, `docs/brand/assets/`.

### 7. Бюджет

- Три пресета: **минимальный / рекомендуемый / охватный** (на ~7 дней).
- Свой бюджет: **не ниже 300 ₽** (без НДС) на период.
- Для первого теста: **минимальный** или сумма владельца из [плана северного теста](research-test-noyabrsk-north-direct-2026-08.md) (TBD).

### 8. После создания

1. **Пополнить счёт** → модерация → запуск.
2. **Рекламно-информационные материалы:** доп. объявления (до 20), кнопка CTA.
3. **Цели:** подключить счётчик `111134477`, выбрать цели вручную (см. ниже).

## UTM (обязательно на всех ссылках из рекламы)

Шаблон:

```text
?utm_source=yandex&utm_medium=cpc&utm_campaign=simple_start_2026q3&utm_content={группа}&utm_term={ключ}
```

Пример сегментной посадочной:

```text
https://proverkastaza.ru/proverka-severnogo-stazha/?utm_source=yandex&utm_medium=cpc&utm_campaign=simple_start_north&utm_content=h_stazh
```

`Clean-param` в robots уже учитывает `utm_*` — дубли в индексе не плодятся.

## Тексты: канон SFRFR

### Можно

- «не учли стаж», «сверка ИЛС», «северный стаж для пенсии», «архивная справка»
- «готовим документы и план — **подаёте сами**, решает СФР»
- публичные этапы: **3 000 / 5 000 / 8 000 ₽** (диагностика → документы → сопровождение)

### Нельзя

- обещать **сумму пенсии**, **перерасчёт**, «калькулятор выплат»
- «подаём за вас в СФР / Госуслуги»
- СНИЛС, сканы, ПДн в креативах

Эталон: `scripts/assets/copy/submission-position.md`, [playbook-editorial-standard.md](playbook-editorial-standard.md).

### Черновик доп. объявления (до 56 / 81 знаков)

**Заголовок:** Стаж не учли в ИЛС — что сверить  
**Текст:** Сверим трудовую и выписку. План и документы — подаёте в СФР сами. Дистанционно по РФ.

Проверить авто-тексты нейросети **до модерации** — часто добавляет «перерасчёт» / «увеличим пенсию».

## Цели Метрики в кампании

Счётчик: **`111134477`**. Приоритет для оптимизации:

| Цель | Когда |
|------|--------|
| `lead_ok` | успешная заявка WPForms |
| `max_click` / `max_chat_click` | клик в MAX |
| `lead_start` | фокус на форме |
| `phone_click` | звонок (если ведём на tel:) |

Автоцели Метрики («Автоцель: …») можно оставить, но **ручные цели** из §7.2 точнее для нашей воронки.

После запуска: в Метрике проверить клики с `utm_source=yandex`.

## После запуска (14 дней)

1. **Директ:** вкладки «Клики» и «Конверсии» на главной кампании.
2. **Метрика:** визиты с `utm_source=yandex`, цели `lead_ok`, MAX.
3. **amoCRM:** лиды с UTM, не дублировать воронку канала MAX.
4. **weekly-template.md** + [max-funnel-control.md](reports/max-funnel-control.md).

Если за **14 дней** нет эффекта — поддержка Директа или переход на **ручной поиск** по [семантике](research-seo-problem-clusters-wordstat-2026-08.md).

## Ограничения Простого старта

- **Не редактировать** авто-объявления — только добавлять свои (до 20).
- **Нет** детальной статистики по каждому авто-баннеру на главной — только в разделе «Кампании».
- Ссылка на **маркетплейс / Telegram / VK** перенаправит в **Мастер кампаний**, не Простой старт.
