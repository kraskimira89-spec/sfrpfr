# Research: запросы «калькулятор / расчёт пенсии / калькулятор стажа»

**Дата:** 2026-08-13  
**Сайт:** https://proverkastaza.ru/  
**Связано:** [ТЗ-18](../specs/18-seo-strategy-and-implementation.md), [seo-semantics-map.md](../ops/seo-semantics-map.md)

## Цель

Понять спрос пенсионеров и предпенсионеров на формулировки вроде «пенсионный калькулятор», «расчёт пенсии», «калькулятор стажа» и решить, **куда** вести трафик на нашем сайте без обещания суммы выплат и без имитации СФР.

## Метод

1. Seed-фразы + выдача Яндекса/Google (desktop): кто в топе — гос / медиа / коммерческие калькуляторы.
2. Сводка открытых источников 2026: официальный прогноз — калькулятор и сведения СФР / Госуслуги; коммерческие калькуляторы считают «по баллам» приблизительно.
3. Wordstat-кабинет в этом прогоне не подключали — частоты ниже **качественные** (высокая/средняя); уточнить числа в следующем спринте.
4. Кластеризация по **интенту**, не только по словам.

## Выводы по выдаче

- Навигационный спрос «официальный калькулятор» закрывает **СФР** — конкурировать нельзя и не нужно (ТЗ-18 §2.3).
- Коммерческие «калькуляторы 2026» дают приблизительную сумму по формуле баллов; наш продукт — **проверка учтённого стажа и документов**, не прогноз выплат.
- Запросы про **стаж** ближе к конверсии в диагностику, чем «сколько рублей будет пенсия».

## Решение о новых URL

| Вариант | Решение |
|---|---|
| Отдельный `/kalkulyator-pensii/` с суммой | **Нет** |
| Страница «Чем калькулятор СФР отличается от проверки стажа» | **Отложить** (P2): пока достаточно блоков на FAQ + услуге; нет каннибализации с `/proverka-stazha/` |
| Ключи на существующих URL | **Да** (P0): ИЛС, сверка, FAQ, услуга |

- «Здесь нет калькулятора стажа, потому что…» (стаж по ИЛС и трудовой, не формула онлайн);
