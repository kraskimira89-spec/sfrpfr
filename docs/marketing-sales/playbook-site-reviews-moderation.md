# Очередь цитат для /otzyvy/ и главной (модерация)

**Дата:** 2026-08-13  
**Канон:** рейтинг только Яндекс; цитаты на сайте — после модерации.

## UX для клиента (быстро и понятно)

На https://proverkastaza.ru/otzyvy/ :

1. **Три вопроса** (карточки, мультивыбор где нужно).  
2. **«Собрать черновик»** — ИИ/шаблон, текст сразу на экране.  
3. Клиент правит черновик и выбирает:
   - **Отправить на сайт** — только с галочкой согласия → очередь `pending`;
   - **Публиковать на Яндексе** — копирует + `/otzyv/`.  
4. Запасной путь без ИИ: [шпаргалка Яндекс Формы](https://forms.yandex.ru/cloud/6a7db97670ad3712589c7456/).

Не публикуем «всё подряд»: на витрину попадают только `published`.

## Файлы / API

| Что | Где |
|-----|-----|
| Хранилище | `var/site_reviews.json` на API-хосте |
| Публичный список | `GET /api/public/site-reviews` |
| Черновик | `POST /api/public/review-draft` |
| В очередь на сайт | `POST /api/public/site-reviews` (текст + согласие + капча) |
| Анкета-алиас | `/anketa-otzyv/` (ведёт на тот же API) |
| CLI | `sfrfr site-reviews-list` / `sfrfr site-reviews-set` |

## Команды

```bash
# На VPS в /opt/sfrfr
.venv/bin/sfrfr site-reviews-list --status pending
.venv/bin/sfrfr site-reviews-set <uuid> --status published
.venv/bin/sfrfr site-reviews-set <uuid> --status rejected
```

## Правила модерации

- Без ФИО, СНИЛС, сумм пенсии, номеров дел.
- Без «поставьте 5» и обещаний перерасчёта.
- Короткий текст о сервисе (ясность, сроки, удобство).
- Не публиковать «всё подряд»: только `published` попадают на `/otzyvy/` и главную.

## Витрина

- `/otzyvy/`: вопросы → черновик → согласование + Яндекс + карточки `published`.
- Главная `#otzyvy`: бейдж + 2–3 цитаты + ссылка «Все отзывы».
