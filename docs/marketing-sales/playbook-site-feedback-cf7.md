# Обратная связь на сайте (Contact Form 7)

**Дата:** 2026-08-22  
**Решение:** одна форма с темой-списком. Тема по умолчанию зависит от страницы.

## Почему не несколько форм

Клиенту проще одна знакомая форма: тема уже выбрана, её можно сменить.  
Менеджеру проще один ящик: письма на `info@proverkastaza.ru` с темой в теме письма, копии во **Flamingo** (Контакт → Входящие). Не нужно помнить, какая форма с какой страницы.

Заявку на услугу (главная → amo) и партнёрскую форму не трогаем.

## Где стоит

| Страница | Тема по умолчанию |
|---|---|
| `/kontakty/` | Другой вопрос |
| `/proverka-stazha/` | Проверка стажа |
| `/proverka-severnogo-stazha/` | Северный стаж |
| `/stazh-do-2002/` | Стаж до 2002 |
| `/proverka-stazha-pered-pensiey/` | Перед пенсией |
| `/pomoch-rodstvenniku-proverit-stazh/` | Помочь родственнику |
| `/tarify/` | Тарифы |
| `/kak-rabotaem/` | Как работаем |
| `/ne-uchli-stazh/` | Не учли стаж |
| `/arhivnaya-spravka-stazh/` | Архивная справка |
| `/otkaz-sfr/` | Отказ СФР |
| `/expert/` и профили | Другой вопрос |

Не ставим на главную (`/#zayavka` → WPForms → amo), `/partneram/`, `/otzyvy/`, юр. страницы.

## Поля

Тема (список) · ФИО · почта · телефон · сообщение · согласие (`/soglasie/`).  
Без СНИЛС и сканов. Документы — только в кабинете после диалога.

## Как смотреть обращения

1. Почта `info@proverkastaza.ru` — тема письма: `[Проверка стажа] Обратная связь: …`.
2. WordPress → **Контакт → Входящие** (плагин Flamingo).
3. Ответ клиенту: Reply-To = его почта.

## Что не менять вручную в админке

Форму «Обратная связь» перезаписывает деплой (`wp_ensure_cf7_feedback.php`). Правки полей — в репозитории, не в UI Contact Form 7.
