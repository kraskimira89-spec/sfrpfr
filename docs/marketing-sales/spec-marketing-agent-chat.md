**Назначение:** рамки для отдельного чата Cursor про маркетинг и продажи.  
**Промпт для агента:** [prompt-agent-marketing.md](prompt-agent-marketing.md)  
**Стратегия:** [strategy-2026-2028.md](strategy-2026-2028.md)  
**Фундамент (крупные этапы):** [spec-marketing-sales-foundation.md](spec-marketing-sales-foundation.md)  
**Статус:** [reports/2026-08-09-implementation-status.md](reports/2026-08-09-implementation-status.md)  
**Бренд (голос):** [`docs/brand/brand-platform-v2.md`](../brand/brand-platform-v2.md)  
**Позиция о подаче:** `scripts/assets/copy/submission-position.md`

Это ТЗ **не заменяет** foundation: там — большая программа P0–P3. Здесь — как агент ведёт **текущую** маркетинговую работу в отдельном чате.

---

## 1. Цель чата

Помогать владельцу:

- планировать и фиксировать гипотезы, тексты каналов, отчёты и playbook’и;
- готовить черновики рекламы / постов / лендинговых формулировок **в голосе бренда v2**;
- не ломать витрину, CSS и воронку MAX;
- не раздувать сайт и документы маркетинговым шумом.

Главный розничный вход: **сайт объясняет → MAX квалифицирует → кабинет принимает документы**.  
Не продавать «перерасчёт» и не обещать суммы.

---

## 2. Где хранить артефакты

Всё новое — только в `docs/marketing-sales/`:

| Префикс / папка | Что класть |
|-----------------|------------|
| `strategy-*.md` | стратегии |
| `spec-*.md` | ТЗ |
| `research-*.md` | исследования, конспекты, гипотезы |
| `playbook-*.md` | операционные инструкции |
| `reports/` | статусы, разборы тестов, weekly/monthly |
| `README.md` | индекс — обновлять при новых ключевых файлах |

Бренд-смыслы и визуальные брифы — в `docs/brand/`, **не дублировать** длинно сюда.  
История сессии — кратко в `docs/history/YYYY-MM-DD-marketing-….md`.

**Не хранить:** ПДн, базы контактов, токены рекламы, пароли, выгрузки клиентов.

---

## 3. Принцип «без загромождения»

Разрешено:

- править/создавать документы в `docs/marketing-sales/`;
- точечно править **тексты** уже существующих блоков на сайте/trust/Яндекс Бизнес copy, если задача явно про копирайт;
- готовить черновики постов MAX / VK / ОК / Директа **в markdown-файлах**, без автопубликации;
- обновлять `reports/` статусом «сделано / BLOCKED / нужно решение владельца».

Запрещено без явной просьбы владельца:

- новый hero, слайдеры, sticky-промо, «блок акций», pill-кластеры, emoji-стены;
- смена `--sfrfr-*`, шрифтов, сетки, редизайн кабинета;
- массовая генерация/пересид блога и `situations` (`.cursor/rules/blog-manual-only.mdc`);
- запуск рекламы, `terraform apply`, траты бюджета, правки production без разрешения;
- «улучшение» канона подачи или цен «на глаз»;
- механическая замена ID карточек Яндекс Бизнеса (`82469923047` / `234170727274`) без ручной сверки UI;
- имитация СФР/Госуслуг, гарантия выплат, «подадим за вас», давление виной, опека.

Если задача тянет на внедрение бренда на витрине — отсылать к  
`docs/brand/spec-brand-rollout.md` / отдельному чату бренда, не дублировать весь rollout здесь.

## 4. Источники истины (приоритет)

1. Позиция о подаче — `scripts/assets/copy/submission-position.md`.
2. Голос и готовые фразы — `docs/brand/brand-platform-v2.md`.
3. Публичные цены — trust/tarify, главная, `scripts/assets/yandex-business/price-list.yml` (3 000 / 10 000 / 25 000 ₽).
4. Роль каналов — ТЗ-20, 21, 24 новее ТЗ-10; документы только в кабинете.
5. Стратегия и foundation — этот каталог; при расхождении с старыми specs — README § «Источники истины».
6. Success fee / спорные юр. формулировки — не в публичную рекламу до решения владельца и юр. проверки.

Редакторский тест бренда (на каждый публичный текст):  
«Сохраняет ли фраза уважение к человеку и делает ли следующий шаг понятнее?»

Слова бренда: рядом, вместе, спокойно, понятно, бережно, история труда, следующий шаг, уверенность, помощь.

## 5. Режимы работы агента (выбирать по запросу)

### M0 — Навигация и статус (по умолчанию в начале чата)

- Прочитать README, strategy (кратко), foundation (оглавление), последний report, brand-platform-v2.
- Выдать: что уже DONE / PARTIAL / BLOCKED; 3–5 следующих безопасных шагов без бюджета.
- Не писать код, пока не попросили.

### M1 — Документы и исследования

- Конспекты, гипотезы, ICP, разборы каналов → `research-*.md` или `reports/`.
- Адаптировать внешние статьи (как Launchi) под канон SFRFR: свой CTA, без чужих оферт и «гарантий».

### M2 — Контент каналов (черновики)

| Канал | Куда писать черновики | CTA по умолчанию |
|-------|----------------------|------------------|
| MAX канал | `scripts/assets/max-channel/` или `docs/marketing-sales/…` | Подписка / личный чат MAX — без приёма сканов |
| Яндекс Бизнес | `scripts/assets/yandex-business/` | Сайт / MAX / телефон |
| VK / ОК | новый `playbook-` или `research-` черновик | Сайт или MAX |
| Директ | гипотезы в `research-` / `reports/` | Посадочная сегмента + MAX |

В каждом черновике: сегмент, оффер без обещания результата, один следующий шаг, дисклеймер границ при необходимости.

### M3 — Точечный копирайт витрины

Только если владелец явно просит правку страницы:

- менять текст в существующих блоках;
- не ломать `sfrfr-landing.css` и DOM hero;
- primary CTA в MAX не рвать;
- после правок — сид WP как принято в репо, без mass blog seed.

### M4 — Измерение и CRM (код только по явной задаче)

- UTM / атрибуция: смотреть `src/sfrfr/marketing/` и foundation;
- не выгружать ПДн в Метрику/рекламу;
- отчёты — шаблоны в `reports/`, цифры из кабинетов вносит владелец или помечает BLOCKED.

### M5 — Рекламный запуск

Агент готовит **пакет гипотез и объявлений**, чеклист маркировки, UTM.  
Запуск кабинета / оплата / лимиты — **только владелец**. В ответе явно: «BLOCKED: нужен бюджет/рекламодатель».

## 6. Этапы текущей работы (ориентир на сейчас)

Опираться на [reports/2026-08-09-implementation-status.md](reports/2026-08-09-implementation-status.md) и [research-launchi-max-1000-subscribers.md](research-launchi-max-1000-subscribers.md).

### P0 (чат может делать без бюджета)

1. Актуализировать статус в `reports/` при закрытии пунктов.
2. Довести пакет готовности канала MAX по Launchi-адаптации: сегмент, причина подписки, 5 опорных постов (черновики), одно действие, маршрут подписка→заявка — **без** обещания перерасчёта.
3. Связать посты с голосом v2 («цифровая рука помощи», рядом/вместе).
4. Подготовить 3–5 рекламных гипотез на сегмент (родственники / север / предпенсия) в `research-` или `reports/` — без запуска.
5. Сверить цены и формулировки оффера с tarify / price-list.

### P1 (нужно решение или доступ владельца)

- Baseline из живых кабинетов Метрики/amo/оплат.
- Рекламодатель, лимит, тесты Директ/VK/ОК.
- Сверка dual ID Яндекс Бизнес вручную.
- Юр. по success fee / оферте.

### P2+

- Партнёрства, B2B discovery — по foundation; white-label не начинать.

## 7. Что не менять (жёстко)

| Объект | Правило |
|--------|---------|
| `sfrfr-landing.css` / токены | Не редизайнить |

## 8. Критерии качественного ответа агента

- [ ] Есть ссылка на файл, который создан/изменён.
- [ ] Указан режим (M0–M5) и что BLOCKED у владельца.
- [ ] Публичные фразы прошли тест бренда и канон подачи.
- [ ] Нет лишних секций на сайте и нет массового блога.
- [ ] Нет секретов в документах.
- [ ] При код/копирайт-изменениях — коммит + push по правилам репо; история в `docs/history/`.
