## Источники

- API Вебмастера v4, `important-urls` (снято 27.09, 12:08): 9 URL со статусом `LOW_QUALITY` («низкое качество / недостаточно востребована»). В аудите утром их было 10; десятая — статья `/blog/kak-pomoch-rodstvenniku-proverit-stazh/`, с #96 она отдаёт 301 на посадочную.

- Что ещё полезно (ручная правка посадочной, 299 слов): перенести из статьи разделы «что подготовить перед запросом», «пошаговый маршрут поиска архива», «если архив не нашёл документы»; добавить блок «что указать в запросе в архив» (ФИО и все прежние фамилии, название организации и период, должность, цель — для СФР) и ссылку на [подтверждение стажа на sfr.gov.ru](https://sfr.gov.ru/grazhdanam/personificirovannyj_uchet/podtverdit_stazh).

### 4. `/pomoch-rodstvenniku-proverit-stazh/` — P1, дописать

- Самая тонкая страница (240 слов, 3 раздела).
- Спрос: кластер 7 в CSV без частоты; перед правкой снять в Wordstat варианты «помочь родителям с пенсией», «проверить стаж мамы/папы», «доверенность в СФР» — в CSV их нет, это гипотезы.
- Чего не хватает:
  - шагов из бывшей статьи `06-dlya-rodstvennikov.html`: согласие пенсионера, когда нужна доверенность, как родственник помогает получить выписку ИЛС (вход в Госуслуги делает сам пенсионер или с ним рядом);
  - чек-листа «что подготовить вместе с родителем»: трудовая книжка, справки, свежая выписка ИЛС;
  - блока «если родитель далеко / плохо видит / не пользуется Госуслугами»: запись в клиентскую службу СФР; МФЦ — запасной канал с обязательной формулировкой;
  - примера (без ПДн): «дочь помогает маме сверить северный стаж»;
  - FAQ «может ли родственник подать заявление» — только по доверенности и по правилам СФР; решение принимает СФР.
- Цель: 700–900 слов, H1 с «помочь родственнику проверить стаж» оставить.

## После правок

1. Деплой штатно, затем `scripts/yandex_webmaster_recrawl.py <URL…>` по изменённым страницам.

3. Мониторинг важных страниц: убрать URL с 301/404 (см. [webmaster-diagnostics-2026-09-27.md](webmaster-diagnostics-2026-09-27.md)).
