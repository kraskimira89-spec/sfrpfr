# Wordstat: пенсионеры × АЗРФ / Крайний Север / приравненные (2026-08-14)

**Справочник регионов:** [wordstat-north-regions.json](wordstat-north-regions.json)  
**Скрипт обхода:** `scripts/wordstat_fetch_north_regions.py`  
**Источники перечней:** сухопутные территории АЗРФ; ПП РФ от 16.11.2021 № 1946.

## Зачем

1. Сначала добавить **гео-обход** по субъектам Арктики, Крайнего Севера и приравненных местностей.  
2. Затем продолжить семантику «как ищут пенсионеры» и внедрить лексику на посадочную/блог/Директ.

## Баг гео

В `wordstat_fetch_7_clusters.py` ID **ЯНАО** был `10842` — это **Архангельская область**. Правильный ID ЯНАО: **`11232`**. Исправлено; прошлые колонки `ЯНАО:` в CSV 7 кластеров считать недостоверными до пересъёма.

## Внедрение (сделано вместе с этим отчётом)

1. JSON-справочник + скрипт обхода.  
2. Исправлен ID ЯНАО; расширен `GEO_REGIONS` в fetch 7 кластеров.  
3. Посадочная `/proverka-severnogo-stazha/`: title/seo + лид с «пенсия в районах Крайнего Севера / приравненные».  
4. Блог север: усилены «крайний север» / «приравненные» / «пенсия приравненные».  
5. Приоритет Директ `region_bucket=north_priority`: список субъектов из JSON (crawl_priority).

## Как добрать матрицу частот по регионам

Квота API ~100 req/час. Скрипт по умолчанию держит **80/час**, при 429 ждёт и **продолжает до полного заполнения**:

```powershell
.\.venv\Scripts\Activate.ps1
python scripts/wordstat_fetch_north_regions.py --list
python scripts/wordstat_fetch_north_regions.py --until-done --rph 80
```

Прогресс: `wordstat-north-geo-matrix.csv` (+ `wordstat-north-geo-matrix-YYYY-MM-DD.csv`).
РФ seed: `wordstat-north-phrases-rf-YYYY-MM-DD.csv`.
