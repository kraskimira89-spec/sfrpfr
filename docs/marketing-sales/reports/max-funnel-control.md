# Контроль воронки MAX (еженедельно)

Простая таблица по этапам Launchi: увидели → перешли → подписались → CTA/написали → уточнили → клиенты.

## Где лежит рабочая копия

| Место | Путь |
|-------|------|
| Яндекс Диск | `disk:/SFRFR-ops/marketing-max-funnel/` |
| Файл на Диске | `max-funnel-weekly.csv` (+ эта инструкция `README-max-funnel.txt`) |
| Копия в репозитории | `docs/marketing-sales/reports/max-funnel-weekly.csv` |

Политика Диска: только ops без ПДн. ФИО, телефоны, номера дел — **не** писать в эту таблицу.

В интерфейсе Диска CSV можно открыть как таблицу Яндекс Документов («Открыть» → Таблицы) и дальше вести там; при желании экспортировать обратно в CSV.

## Колонки

| Колонка | Смысл | Откуда брать |
|---------|--------|--------------|
| `week_start` / `week_end` | Неделя (пн–вс) | Календарь |
| `saw_invite_or_ads` | Увидели приглашение / рекламу | Оценка охватов / Директ (когда будет) |
| `channel_visits` | Перешли в канал | Статистика ссылок / UTM / MAX (если есть) |
| `subscribed` | Подписались | Счётчик канала на конец минус начало недели |
| `cta_or_wrote` | Написали / нажали CTA | Личный чат MAX (счёт без имён) |
| `clarified_or_lead` | Уточнили ситуацию / заявка | Кабинет / amo: новые лиды недели |
| `became_clients` | Стали клиентами (оплата) | amo: оплаченная диагностика / сопровождение |
| `source_main` / `source_extra` | Источники 1+1 | Как в Launchi-листе |
| `notes` | Обрыв воронки, гипотеза | Без ПДн |

Где обрыв (падение конверсии между соседними этапами) — чинить обещание, контент, доверие или процесс записи.

## amoCRM — что считать из CRM, а не дублировать воронку канала

amo остаётся CRM сделок. В таблицу MAX переносить **только агрегаты за неделю**:

- `clarified_or_lead` — число новых лидов/сделок из канала MAX;
- `became_clients` — число оплат (диагностика / сопровождение);
- топ `LOSS_REASON` — в еженедельный маркетинговый отчёт (`weekly-template.md`), не в этот CSV.

Не создавать в amo отдельную «таблицу подписчиков канала» — там нет смысла хранить этапы «увидели / подписались».

## Заполнение

1. Раз в неделю (пн) дописать одну строку в CSV / таблицу на Диске.
2. Сверить `became_clients` и лиды с amo.
3. Коротко зафиксировать обрыв в `notes`.
4. Раз в месяц сверить с `weekly-template.md` (сайт + реклама).
