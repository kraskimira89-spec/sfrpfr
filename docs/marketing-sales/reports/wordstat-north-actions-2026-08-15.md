## Главный вывод

Люди ищут **«пенсия крайний север»**, **«северный стаж для пенсии»**, **«приравненные к крайнему северу»**, **«сколько лет / для мужчин / для женщин»**.  
Сервисный канцелярит («проверка периодов ИЛС», «диагностика») без этих слов проигрывает и в SEO, и в Директе.

Границы без изменений: готовим документы и план — подаёте сами — решает СФР; без калькулятора выплат и обещания перерасчёта.

## Сайт — что менять

### P0

1. **`/proverka-severnogo-stazha/`**
   - Title ближе к: «Северный стаж для пенсии / пенсия в районах Крайнего Севера».
   - Видимый H1 (если сейчас только lead) с той же лексикой.
   - Блок: **КС vs приравненные** (разные перечни, сверка периодов, не «жил = льгота»).
   - FAQ: «сколько нужно северного стажа», «для мужчин / женщин» → ответ = сверка документов, не норма «лет до льготы».

2. **Главная / меню / карточки услуг**
   - Анкоры: «Северный стаж для пенсии», «Не учли стаж» — рядом с бытовыми формулировками.

3. **Блог**
   - Усилить / добавить H2 или короткую статью под «пенсия в районах, приравненных к крайнему северу».
   - Связка с «год северного стажа» без обещания итога.

### P1

4. Явно развести **районный коэффициент** и **северный стаж** (разные запросы ~4.5k и ~35k).
5. С северной посадочной — жёсткая перелинковка на **выписку ИЛС** и **отказ в назначении пенсии**.

## Продвижение — что менять

### P0 Директ

- Гео **волна 1** (таблица выше), не только Ноябрьск.
- Группы объявлений по кластерам:
  - северный стаж / для пенсии;
  - пенсия крайний север / в районах КС;
  - приравненные;
  - (отдельно) районный коэффициент → посадочная с дисклеймером «не то же самое».
- Минус-слова: сколько доплатят, калькулятор надбавки, МВД, кадры, отпуск.
- Посадка: только `/proverka-severnogo-stazha/` (+ UTM `region_bucket=north_priority`).

### P1

- Волна 2 гео + узкий тест Магадан/Камчатка.
- **MAX:** 3–4 поста серии «Север»: КС vs приравненные; сколько лет (без гарантии); коэффициент отдельно; CTA на посадочную.
- После правок title — **переобход** Вебмастера.
