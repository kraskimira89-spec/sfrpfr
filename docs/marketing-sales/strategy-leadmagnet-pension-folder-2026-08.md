## 1. Зачем

PDF — не «чек-лист ради скачивания», а **навигационная карта для семьи**: помочь пенсионеру или родственнику **вручную** собрать и разложить документы до обращения в СФР.

**Без:**

- передачи сканов в открытый чат;
- обещаний перерасчёта / «вернём стаж» / калькулятора выплат;
- бесплатной индивидуальной диагностики конкретного ИЛС.

**С:**

- реальной первой пользой за 30–40 минут;
- снятием тревоги («что собрать и куда смотреть»);
- естественным следующим шагом: выписка ИЛС → сверка → при расхождении диагностика (3 000 ₽).

Выписка ИЛС — базовый источник проверки учтённых пенсионных прав; трудовая и архивные справки нужны, когда сведений недостаточно.

## 2. Название и оффер

### Рабочее название

**«Папка пенсионных документов: как собрать и проверить всё вручную»**

Подзаголовок:

> Пошаговый чек-лист для пенсионера и его семьи: что подготовить до проверки стажа и обращения в СФР.

### Ценность (не «скачайте PDF»)

> За 30–40 минут собрать домашнюю папку документов, увидеть, чего не хватает, и понять следующий шаг без лишних поездок и передачи сканов незнакомым людям.

### A/B заголовки (после MVP)

1. Не потерять стаж: домашний чек-лист документов  
2. Проверка пенсионных документов: начните с папки, а не с тревоги  
3. Документы для проверки стажа: порядок для себя и родителей  
4. Как собрать документы, если в ИЛС есть пропуски  

### Для кого

- родственники 40–60 лет, помогающие родителям;  
- пенсионеры и предпенсионеры;  
- люди с пропусками в ИЛС / непонятным периодом / подготовкой к СФР;  
- архивный, северный, льготный, «советский» стаж — **без обещания**, что он будет учтён.

## 3. Структура PDF (6–8 страниц)

Крупный шрифт, мало канцелярита, поля для отметок ручкой.

| № | Блок | Содержание |
|---|------|------------|
| 1 | Обложка | Название + «для себя или родителей» + дисклеймер СФР |
| 2 | Как пользоваться | Папка, ручка, Госуслуги, трудовая; правило: оригиналы у себя, сканы не в открытый чат |
| 3 | Базовая папка | 4 раздела: личные / работа / пенсионные сведения / доп. подтверждения |
| 4 | Получить ИЛС | Шаги Госуслуги (+ СФР/МФЦ); дата получения; **без персонализированных QR/UTM в PDF** |
| 5 | Ручная сверка | Таблица «Да / Нет / Не знаю» (места работы, даты, пропуски, ФИО, спорные периоды, ответ СФР) |
| 6 | Карточка спорного периода | 1–2 пустые формы |
| 7 | Если документов нет | Организация / правопреемник / город / трудовая / архив; без гарантий |
| 8 | Следующий шаг | Всё совпадает → хранить; расхождение → карточка + CTA в MAX «Нужна проверка документов» |

### 4 раздела домашней папки

| Раздел | Что положить |
|--------|--------------|
| 1. Личные | Паспорт, СНИЛС, смена ФИО — **хранить у себя** |
| 2. Работа | Трудовая, сведения о трудовой, договоры, приказы, справки |
| 3. Пенсионные сведения | Выписка ИЛС, ответы СФР, уведомления, заявления |
| 4. Доп. подтверждения | Архив, служба, уход, учёба, особые периоды — если относится |

PDF **не** советует отправлять эти документы сервису — только домашняя структура.

### CTA в PDF (мягкий)

> Нужна помощь с разбором выписки ИЛС и документов?  
> Напишите в MAX: **«Нужна проверка документов»**.  
> Мы объясним порядок диагностики и стоимость до начала работы.

Ниже: `proverkastaza.ru` + дисклеймер СФР / позиция «готовим — подаёте сами».

## 4. Воронка лид-магнита

### Этап 1. MVP

- Один PDF + посадочная **`/chek-list-dokumentov/`**
- Проблема → 3 результата → форма: имя + канал ответа  
- Согласия: **обязательное ПДн** на выдачу; **необязательное** маркетинг по каналу  
- Без СНИЛС, ДР, адреса, сканов, «опишите проблему»

### Этап 2. Выдача и диалог

1. Дело / лид типа `lead_magnet_checklist` (или эквивалент в amo/кабинете).  
2. Ссылка на PDF (предпочтительно), не обязательно вложение.  
3. Теги: `leadmagnet`, `manual_docs`, `source`, `channel`, `marketing_consent`, `checklist_sent`.  
4. Микродействие **до** продажи диагностики:

> Когда получите выписку ИЛС и заполните карточку спорного периода, ответьте:  
> **«ИЛС получил(а)»** или **«Есть расхождение»**.

### Этап 3. Сегментация по готовности

| Сигнал | Сегмент | Следующий шаг |
|--------|---------|---------------|
| Скачал, молчит | Изучает | 1 сервисное напоминание через 5–7 дней (если уместно и по правилам касаний) |
| Не могу получить ИЛС | Цифровой барьер | Короткая инструкция / помощь родственнику |
| Есть расхождение | Проблемный | Предложить диагностику |
| Документов нет | Архивный | Карточка периода |
| Всё совпадает | Самопомощь | Поблагодарить, не продавать |
| Нужна проверка | Горячий | Уточнить → диагностика |

### Этап 4. Конверсия в диагностику

Триггер (канон цены 3 000 ₽):

> Если в ИЛС нет периода, даты расходятся с трудовой или непонятно, каких документов не хватает, можно провести диагностику. Мы сверим документы, отметим возможные расхождения и подготовим план действий. Стоимость — 3 000 ₽. Решение о перерасчёте принимает СФР.

**Запрещено в лид-магните:** «бесплатная консультация по пенсии», «увеличим пенсию», «проверим всем бесплатно».

### Этап 5. Метрики

| Метрика | Смысл |
|---------|--------|
| Посетители лендинга | Спрос |
| Конверсия в PDF | Понятность оффера |
| Открыли / скачали | Качество выдачи |
| «ИЛС получил(а)» | Польза |
| «Есть расхождение» | Квалификация |
| Диагностика предложена / оплачена | Продажа |
| Отказы / отписки | Доверие и частота |

Ориентир гипотезы (не норма рынка):

```text
100 визитов → 15–30 PDF → 5–10 микродействий → 2–4 релевантных → 1 диагностика
```

После **30–50** выдач — решения по данным.

Максимум **два** сервисных касания без нового действия клиента.

## 5. Каналы (без бюджета сначала)

1. Статьи: ИЛС, документы для проверки стажа, ликвидированный работодатель.  
2. MAX-канал: ссылка на чек-лист, без сбора сканов.  
3. Партнёры / НКО: нейтральная раздача, без передачи ПДн партнёрам.  
4. Вебинар для родственников (позже).  
5. Директ — **после** проверки конверсии лендинга → диагностики.

Реклама в мессенджерах — только с предварительным согласием и возможностью отказаться.

## 7. Что не делать

- Только телефон без альтернативы e-mail / страница скачивания.  
- Обязательный маркетинг.  
- Обещания повышения пенсии / перерасчёта / «вернуть стаж».  
- PDF = бесплатная диагностика ИЛС.  
- Просьба прислать сканы в MAX.  
- Сразу к оплате без микродействия.  
- Регулярные напоминания без согласия и логики завершения.

---

## 8. Финальная формула

```text
Польза:      помогаем семье самостоятельно собрать документы
Микродействие: получить ИЛС + одна карточка спорного периода
Квалификация: есть расхождение / нет документов / всё совпадает
Продажа:     платная диагностика + индивидуальный план (решает СФР)
```
