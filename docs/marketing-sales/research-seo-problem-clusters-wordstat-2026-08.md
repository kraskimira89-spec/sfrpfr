# Research: Wordstat-семантика — 7 проблемных кластеров

**Дата:** 2026-08-13  
**Сайт:** https://proverkastaza.ru/  
**Канон кластеров:** PDF «начнем с исследования proverkastaza.ru и запросов» (приоритетная очередь)  
**Связано:** [research калькулятор](research-seo-pension-queries-2026-08.md), [seo-semantics-map](../ops/seo-semantics-map.md), [ТЗ-18](../specs/18-seo-strategy-and-implementation.md)  
**CSV:** [reports/wordstat-7-clusters-template.csv](reports/wordstat-7-clusters-template.csv)

## Цель

Собрать ядро запросов (~40–80 строк) по **семи** проблемным кластерам и сразу сопоставить каждый head-запрос с **live URL**, черновиками Title / H1 / CTA и минус-словами — без создания новых коммерческих slug и без обещания суммы пенсии.

## Позиция сервиса

Мы готовим документы, проект обращения и план. Подаёте через СФР / МФЦ / Госуслуги вы сами. Решение принимает только СФР. Не подменяем официальную выписку ИЛС и не продаём «гарантированный перерасчёт».

## Метод

1. Seed из PDF + расширения long-tail.  
2. Wordstat РФ + гео через **Search API v2** (`scripts/wordstat_fetch_7_clusters.py`, [ops](../ops/yandex-wordstat-setup.md)).  
   На 2026-08-13: **19/47** фраз с `freq_rf` (квота 100 req/час; гео съела лимит). Остальные — добрать командой `python scripts/wordstat_fetch_7_clusters.py --no-geo` после сброса квоты.  
3. Маппинг на **существующие** trust/blog URL; candidate slug из PDF — только как gap P1.  
4. Интент: информационный / диагностический / проблемный / транзакционный / горячий.

## Минус-слова (черновик для Директа / кластеризации)

Общие: `вакансия`, `работа`, `курс`, `реферат`, `украина`, `казахстан`, `скачать закон`, `калькулятор пенсии онлайн` (если ведёт к обещанию суммы — отдельный кластер, см. research калькулятор), `бесплатно скачать`, `форум скачать бланк` (шум).

Кластер 5 (отказ): осторожно с `адвокат суд иск` без квалификации услуги — мы не обещаем обжалование «под ключ» как юрфирму.

Кластер 4 (север/перерасчёт): минус формулировок «гарантированная прибавка», «сколько доплатят».
