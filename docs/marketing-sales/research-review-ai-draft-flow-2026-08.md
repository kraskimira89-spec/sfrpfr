# Поток отзыва: анкета → ИИ-черновик → клиент публикует в Яндексе

**Дата:** 2026-08-13  
**Статус:** MVP реализован (сайт + кабинет + MAX)  
**Связано:** ТЗ-19, `playbook-yandex-form-review-prompts.md`, `/otzyv/`, `/anketa-otzyv/`

## Вердикт

**Да, так лучше.** Наводящие вопросы + черновик отзыва (ИИ или шаблон) + кнопка «Публиковать отзыв» (открыть Яндекс) — проще для клиента 55+ и честнее, чем «напишите сами».

Публикует **только клиент** в форме Яндекса. Мы не постим отзыв за него и не подставляем «пять звёзд».

## Целевой сценарий (как в MVP)

```text
Дело completed
  → мягкое приглашение в MAX (кнопки) + блок в кабинете
  → анкета 3 вопроса (сайт /anketa-otzyv/ или кнопки в MAX)
  → «Собрать текст отзыва» (LLM с fallback-шаблоном)
  → черновик + «Скопировать»
  → «Публиковать отзыв» → https://proverkastaza.ru/otzyv/ → Sprav
  → клиент вставляет текст и сам ставит оценку
```

## Где сделано

| Канал | URL / точка | Что |
|-------|-------------|-----|
| Сайт | https://proverkastaza.ru/anketa-otzyv/ | Анкета + SmartCaptcha + API черновика |
| Публикация | https://proverkastaza.ru/otzyv/ | Редирект на форму Яндекса |
| API | `POST /api/public/review-draft` | Черновик без ПДн |
| Кабинет | после `pipeline_status=completed` | CTA на анкету и `/otzyv/` |
| MAX | soft-ask + callbacks `review:*` | 3 вопроса кнопками → черновик → ссылка |

Код: `src/sfrfr/core/review_draft.py`, `api/routes/public_review_draft.py`, `integrations/max/review_flow.py`, `scripts/assets/trust/anketa-otzyv.html`.

## Правила для черновика

- От первого лица по ответам; не выдумывать факты.  
- Без СНИЛС, паспорта, сумм пенсии, «поставьте 5».  
- Канон подачи: готовим / подаёте вы / решает СФР.  
- Forms-помощник — **временный запасной** канал без ИИ (не развивать).

## Границы (нельзя)

- Автопубликация отзыва.  
- Бонус / скидка за отзыв.  
- Серия напоминаний (1 авто + 0–1 ручное).  
- Хранить ПДн из анкеты (ответы — в сессии MAX / одноразовый POST).
