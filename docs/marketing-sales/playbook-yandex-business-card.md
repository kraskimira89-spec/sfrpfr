## Отзывы (ежедневно)

Из PDF:

1. Проверять раздел «Отзывы» **каждый день**.
2. Отвечать **публично**, персонально.
3. Предлагать продолжить диалог **не через просьбу оставить контакты в отзыве** (пользователь этого не сможет) — направлять на MAX / сайт / почту компании.
4. Негатив — не отвечать сгоряча.

### Структура ответа на негатив (PDF → SFRFR)

| Шаг PDF | Как у нас |
|---------|-----------|
| Благодарность / извинения | Да |
| Эмпатия, не отрицать проблему | Да |
| Факты, без оправданий; не писать пустое «к сожалению» вместо признания | Да |
| Какие меры приняты | Улучшение ясности инструкций / сроков ответа — без обещания перерасчёта |
| Компенсация / подарок / скидка | **Не** «за отзыв» и не бонус за оценку (ТЗ-19). Компенсация услуги — только по решению владельца вне публичного ответа |
| Приглашение к диалогу | MAX на proverkastaza.ru или `info@proverkastaza.ru` |

Шаблоны: `scripts/assets/yandex-business/review-reply-templates.md`.  
Промо QR/визитка/буклет — размещать у клиентов (PDF: «распечатайте и разместите»).

## УТП (из PDF)

Формула: **предложение + ключевая выгода**.

Черновик SFRFR (согласован с Launchi / описанием канала):

> Помогаем пенсионерам сверить трудовую с выпиской ИЛС из Госуслуг и подготовить проект обращения — подаёте сами, решение принимает СФР.

Перед правкой оффера в карточке: глянуть конкурентов в Картах Ноябрьска / ЯНАО / «проверка стажа».

## Не делать в карточке

- гарантия перерасчёта / суммы выплат;
- образ «мы — СФР / Госуслуги»;
- ПДн и сканы в форме, публикациях, историях;
- доставка «для галочки»;
- смена ID карточки без владельца (канон `82469923047`).
