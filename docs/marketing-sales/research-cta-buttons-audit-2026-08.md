# Аудит кнопок перехода (CTA) — взгляд маркетолога

**Дата:** 2026-08-13  
**Вердикт:** разнообразие **лишнее** — один главный путь размыт синонимами и конкурирующими secondary.

## Что должно быть одним маршрутом

По Launchi и стратегии:

1. **Диалог** → личный чат MAX (`MAX_BTN_URL`)
2. **Документы** → кабинет (после диалога / по прямой ссылке только в блоке «Как пользоваться MAX»)
3. **Польза без диалога** → канал MAX (не конкурирует с заявкой)

Форма `#zayavka` и телефон — запасные входы для тех, кто не в MAX, не равноправные «главные» кнопки на каждом экране.

### Синонимы одного действия (ломают узнаваемость)

1. «Уточнить ситуацию в MAX»
2. «Написать в личный чат MAX»
3. «Начать в MAX»

Для метрик и привычки 55+ нужна **одна** формулировка.

### Конкурирующие «вторые» кнопки

- Позвонить  
- Оставить заявку  
- Читать канал / Личный кабинет (как кнопки рядом с primary)  
- Открыть страницу тарифов (как primary)

Итог: посетитель не запоминает «куда жать всегда».

## Канон CTA (рекомендация)

### Подписи

| Роль | Текст | Куда |
|------|--------|------|
| **Primary** (везде) | Уточнить ситуацию в MAX | `{{MAX_BTN_URL}}` |
| **Secondary A** (hero / FAQ / sticky-пара) | Позвонить | `tel:+79091950408` |
| **Secondary B** (только блок заявки / блог) | Оставить заявку | `/#zayavka` |
| Канал / кабинет / тарифы / статьи | **текстовая ссылка** или ghost **вне** hero | без primary-стиля |

Запрет: менять primary-текст; делать primary из тарифов/блога/кабинета.

### Раскладка по типам страниц

1. **Hero (главная и сегменты):** primary MAX + **одна** secondary — **Позвонить**. Убрать «Оставить заявку» из hero (форма остаётся внизу страницы / на главной).
2. **Низ сегментных страниц:** та же primary-подпись, не «Начать в MAX».
3. **Блок «Как пользоваться MAX»:** объяснить роли карточками; под блоком **одна** primary MAX; канал и кабинет — ghost или text-link, без третьей «равноценной» кнопки рядом по визуальному весу.
4. **Секция тарифов на главной:** primary = MAX; «Страница тарифов» — ghost/link.
5. **Sticky:** только primary MAX (как сейчас).
6. **Контакты:** primary MAX; канал и форма — в тексте, не россыпь primary.

### Почему так

- Один визуальный якорь → выше конверсия в диалог (цель Launchi).  
- Телефон закрывает тех, кто не ставит MAX (аудитория 60+).  
- Форма не исчезает, но не спорит с MAX в первом экране.  
- Канал не должен выглядеть как «вторая заявка».

## Приоритет правок (P0)

1. Унифицировать подписи «Написать…» / «Начать…» → «Уточнить ситуацию в MAX».
2. Сегментные hero: убрать третью кнопку «Оставить заявку».
3. Главная · тарифы: поменять primary/ghost местами.
4. Блок MAX-гайд: ослабить ряд из трёх кнопок (оставить 1 primary + ссылки).

Статус внедрения: **документировано, правки HTML — по явному «внеси»**.
