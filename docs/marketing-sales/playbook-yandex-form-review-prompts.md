# Яндекс Форма: подсказки к отзыву

**Назначение:** клиенту легко ответить на вопросы → получить черновик текста → вставить в [отзыв Яндекс Бизнеса](https://yandex.ru/sprav/82469923047/reviews/add/).  
Это **не** замена отзыва в Картах: форма только помогает написать текст.

**Вопросы-источник:** `scripts/assets/yandex-business/review-prompt-questions.md`  
**Создание через API (нужен 360):** `python scripts/create_yandex_form_review_prompts.py`  
**Статус API:** форма создана 2026-08-13 (`survey_id=6a7db97670ad3712589c7456`).  
Публичная ссылка помощника: https://forms.yandex.ru/cloud/6a7db97670ad3712589c7456/  

**Целевой UX (лучше):** анкета → ИИ-черновик → клиент копирует и публикует в Яндексе —  
[`research-review-ai-draft-flow-2026-08.md`](research-review-ai-draft-flow-2026-08.md). Forms-помощник — временный, без ИИ.

## Создать вручную (рекомендуется сейчас)

1. Открыть https://forms.yandex.ru/ → **Личные формы** (или Формы для бизнеса, если есть 360).
2. **Создать пустую форму**.
3. Название формы: `Проверка стажа — подсказки к отзыву`.
4. Добавить вопросы **по таблице ниже** (типы как указано).
5. В конце / на экране «Спасибо»:
   - заголовок: `Спасибо!`;
   - текст: скопируйте ответы своими словами в отзыв (ссылка ниже). Не указывайте СНИЛС, паспорт и суммы пенсии;
   - кнопка/ссылка: https://yandex.ru/sprav/82469923047/reviews/add/
6. Настройки: форма **без** обязательной авторизации Яндекса; **без** загрузки файлов.
7. Опубликовать → скопировать публичную ссылку → вписать в таблицу внизу этого файла и в `review-prompt-questions.md`.

### Вопросы формы

| # | Тип | Обязательный | Текст вопроса | Варианты / подсказка |
|---|-----|--------------|---------------|----------------------|
| 0 | Текст (комментарий) | — | Подсказка к отзыву о сервисе «Проверка стажа». Отзыв — про нашу работу, не про решение СФР. Без паспортных данных и сканов. | — |
| 1 | Один из списка | да | Чем мы помогли? | Сверили трудовую с выпиской ИЛС; Подготовили план / проект обращения; Перенесли трудовую в таблицу; Помогли разобраться с документами; Другое |
| 2 | Один из списка | да | Было ли понятно и спокойно общаться? | Да; В целом да; Местами сложно |
| 3 | Один из списка | да | Что было удобнее всего? | Личный чат MAX; Личный кабинет; Сроки ответа; Понятные шаги; Пока ничего из этого |
| 4 | Один из списка | нет | Зачем обратились? | Сомневался(ась) в стаже; Помогал(а) родителю / родственнику; Перед пенсией; После отказа или ответа СФР; Другое |
| 5 | Один из списка | нет | Понятна ли граница: мы готовим, подаёте вы, решает СФР? | Да; Стало понятнее; Пока не до конца |
| 6 | Текст (многострочный) | нет | Что улучшить? (одно предложение) | Необязательно |
| 7 | Один из списка | нет | Порекомендовали бы близким при похожей ситуации? | Да; Скорее да; Нет; Пока рано говорить |

Кнопка отправки: `Готово — открыть форму отзыва`.

### Текст для экрана «Спасибо»

```text
Спасибо! Теперь откройте форму отзыва на Яндексе и вставьте 2–4 предложения своими словами
(можно опереться на ответы выше). Оценку звёздами выбираете вы.

https://yandex.ru/sprav/82469923047/reviews/add/

Не пишите в отзыве СНИЛС, паспорт, ФИО третьих лиц и суммы пенсии.
```

### Каркас, который можно показать клиенту рядом со ссылкой (в MAX)

```text
Обращался(ась) за сверкой документов по стажу. Помогли разобраться, что смотреть в выписке ИЛС и трудовой, и что делать дальше. Общение было спокойное и понятное.
```

## Через API (когда появится орг. 360)

1. OAuth-приложение: scope **forms:write** (и при необходимости forms:read).  
   Инструкция: https://yandex.ru/support/forms/ru/api-ref/access
2. В `.env` (не коммитить):

```env
YANDEX_FORMS_ORG_ID=<id организации 360>
YANDEX_FORMS_OAUTH_TOKEN=<токен с forms:write>
# или тот же YANDEX_OAUTH_ACCESS_TOKEN, если scope уже есть
```

3. Запуск:

```powershell
.\.venv\Scripts\Activate.ps1
.\.venv\Scripts\python.exe scripts/create_yandex_form_review_prompts.py
```

Скрипт создаст форму, добавит вопросы, опубликует и выведет URL.
