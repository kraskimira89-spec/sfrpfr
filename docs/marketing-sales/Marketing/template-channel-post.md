# Шаблон поста канала

Для MAX (и адаптации под VK/ОК/Яндекс Бизнес).  
Голос: `docs/brand/brand-platform-v2.md`. Канон подачи — не ослаблять.

```markdown
## Пост: <тема>

**Канал:** MAX  
**Сегмент:**  
**Цель поста:** подписка / доверие / переход в личный чат / напоминание границ  
**Статус:** черновик  

### Текст
<2–8 коротких абзацев. Сначала ситуация и зачем, потом один следующий шаг.>

### CTA (один)
Написать в личный чат MAX / открыть статью на сайте / …

### Границы (если тема про подачу или ожидания)
Короткий вариант: готовим документы и план — подаёте сами — решает СФР.

### Не использовать
Перерасчёт «гарантируем», суммы, «пришлите трудовую сюда», давление, опека.

### Редакторский тест
- [ ] уважение к человеку
- [ ] следующий шаг понятен
- [ ] голос: рядом / вместе / спокойно / понятно
```
