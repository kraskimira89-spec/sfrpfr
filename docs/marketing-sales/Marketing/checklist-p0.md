# Чеклист P0 маркетолога (без рекламного бюджета)

Отмечать в `docs/marketing-sales/reports/` при закрытии.  
Не запускать Директ/VK ads из этого чеклиста.

## Канал MAX

- [x] Приоритетный сегмент сформулирован одной фразой (Launchi + SFRFR). → `research-launchi-max-1000-subscribers.md`, закреп `starter-posts.json` / `channel-description.md`
- [x] Причина подписаться конкретная (коллеги / снижение / сверка ИЛС) — без гарантии выплат.
- [x] Описание канала и навигация согласованы с каноном подачи. → `channel-description.md` + закреп (публикация вручную)
- [x] Черновики ≥5 опорных постов в голосе v2. → `scripts/assets/max-channel/starter-posts.json` (цепочка Launchi; автопубликация — после вычитки владельцем)
- [x] Одно главное действие: личный чат MAX (не «пришлите трудовую в канал»).
- [x] Маршрут: подписка → польза → доверие → предложение диагностики → заявка.

## Сообщения по сегментам

- [ ] Родственники: «рядом / вместе», без опеки и вины.
- [x] Север: отдельные основания, уважение, без «автоматом больше пенсия». → `research-segment-north-2026-08.md`
- [ ] Предпенсия: ясность и следующий шаг, без страха «потеряете».
- [ ] Везде: канон подачи или короткий вариант. *(в пакете «север» — да)*

## Гипотезы (черновики)

- [x] Север: 5 гипотез (`research-segment-north-2026-08.md`) — без запуска.
- [ ] 3–5 гипотез на сегмент родственники / предпенсия → research/reports.
- [ ] UTM-схема названа единообразно (см. код/справочник attribution в репо).
- [ ] Посадочная указана существующая (trust/сегмент), не выдуманный URL.

## Согласованность коммерции

- [ ] Цены 3 000 / 10 000 / 25 000 ₽ совпадают с tarify / price-list.
- [ ] Success fee не светится в рекламе до юр. решения.
- [ ] Яндекс Бизнес: тексты/прайс сверять; dual ID не менять механически.
- [ ] Перенос трудовой в Word — **100 ₽/разворот**; тяжёлый объём — **отдельный счёт после осмотра сканов** (`../playbook-trudovaya-word-table.md`).

## Запреты (проверка перед публикацией черновика)

- [ ] Нет обещания перерасчёта / суммы.
- [ ] Нет «подадим за вас» / «мы — СФР».
- [ ] Нет приёма сканов вне кабинета.
- [ ] Нет редизайна и новых промо-секций на сайте «заодно».

## Когда P0 можно считать готовым к тестам с бюджетом

Есть: сегмент, причина подписки, 5 постов, одно CTA, 3+ гипотезы с UTM и посадочной, канон соблюдён.  
Дальше — решение владельца по бюджету (режим M5 / foundation P1).
