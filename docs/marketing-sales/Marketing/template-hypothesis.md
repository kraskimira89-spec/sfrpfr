# Шаблон гипотезы

Скопировать в `docs/marketing-sales/research-….md` или `reports/….md`.

```markdown
## Гипотеза: <короткое имя>

**Дата:** YYYY-MM-DD  
**Статус:** черновик / согласовано / в тесте / стоп  
**Сегмент:** родственники | север | предпенсия | пенсионер с сомнением  
**Канал:** MAX орг / Директ / VK / ОК / Яндекс Бизнес  

### Формула
Если мы покажем **<сообщение>** сегменту **<кто>** в **<канал>**,  
то получим **<метрика: клик / диалог / заявка>** при цене не выше **<лимит или TBD>**.

### Сообщение (голос v2)
- Заголовок:
- Текст (2–4 предложения):
- CTA: личный чат MAX / страница сегмента / телефон
- Дисклеймер границ (если нужен): канон подачи кратко

### Посадочная
- URL (существующий):
- Что человек должен понять за 5 секунд:

### UTM (черновик)
- utm_source:
- utm_medium:
- utm_campaign:
- utm_content:

### Ограничения
- [ ] нет обещания выплат
- [ ] нет «подадим за вас»
- [ ] документы только в кабинете
- [ ] бюджет не запущен без владельца

### Результат (после теста)
- Показатели:
- Вывод:
- Решение: масштабировать / править / стоп
```
