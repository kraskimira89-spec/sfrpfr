# Playbook: одностраничник для партнёров (черновик)

Для НКО, профсоюзов, ветеранских сообществ и специалистов по архивам.

## Кто мы

Сервис «Проверка стажа» помогает людям сверить ИЛС и документы, собрать чек-лист и план обращения. Клиент подаёт в СФР/МФЦ/Госуслуги сам. Решение принимает только СФР.

## Что предлагаем партнёру

- Понятный маршрут для подопечных: MAX → кабинет → диагностика.
- Без передачи пенсионных файлов через чаты и формы сайта.
- Рекомендательный код (поле `referral_code`) — после утверждения условий владельцем.

## Чего не делаем

- Не покупаем базы и не рассылаем спам.
- Не обещаем прибавку к пенсии.
- Не принимаем документы вне защищённого кабинета.

## Следующий шаг

Связаться: контакты на proverkastaza.ru/kontakty/. Договор и вознаграждение — только после согласования с владельцем.
