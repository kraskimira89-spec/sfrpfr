# Стратегия: оживить ~150 заявок, «зависших на канале»

**Дата:** 2026-10-09  
**Статус:** план волны (ops + контент)  
**Связано:** [реанимация дел](../ops/playbook-case-reactivation.md) · [clarity §5в](playbook-sales-clarity-funnel.md) · [реклама → канал](strategy-ads-to-max-channel-2026-09.md) · [FUNNEL-11](https://tracker.yandex.ru/FUNNEL-11)

---

## 1. В чём проблема

```text
Заявка / личный чат MAX
    ↓
Подписка на канал (прогрев, польза)
    ↓
Человек «читает канал» и не возвращается в личный чат
    ↓
Нет ИЛС / нет согласия / нет оплаты диагностики
```

Канал снижает страх — это нормально. Ошибка — когда канал становится **тупиком** без моста обратно в дело.

**Цель волны:** вернуть ясный следующий шаг в личный чат (ИЛС → документы → диагностика при готовности), а не «дожать до 3 000 ₽».

## 2. Целевые результаты (2–3 недели, из ~150)

| Метрика | Цель | Ориентир |
|---------|------|----------|
| Ответ в личный чат | ≥ 25% | ~40 |
| «ИЛС получил(а)» / «Нужна проверка» | ≥ 12% | ~18 |
| Оплата диагностики 3 000 ₽ | ≥ 5–8% | ~8–12 |
| Отказ / «не беспокоить» | LOSS с причиной | чистая воронка |
| Тишина после касания №2 | archive «можно вернуться» | без спама |

В отчётах — только счётчики и `case_ref` (последние 4 символа id), без ПДн.

## 3. Сегментация до массовой отправки

| Сегмент | Признак | Корзина | Действие |
|---------|---------|---------|----------|
| CH-1 Читатель канала | Есть `max_user_id`, дело есть, мало ответов, нет ИЛС/файлов | A / O | «На каком шаге» + мост из поста |
| CH-2 Чек-лист выдан | Факт выдачи чек-листа / ссылки | B | Сервис §5в №1 → №2 |
| CH-3 Счёт / оффер 3k | Открытый DIAG | C | Напоминание состава диагностики |
| CH-4 Ждём staff | Оплачено / документы есть, тишина с нашей стороны | D | Не писать клиенту — задача сотруднику |
| CH-5 Нельзя | `do_not_contact`, отзыв ПДн | F | Исключить |
| CH-6 >45 дней тишины | Вне окна автотика | E | Канал + win-back только при согласии / ответе |

Приоритет: **D → C → CH-2 → CH-1 → CH-6**.  
Классификация: `sfrfr case-reactivation-due-tick --dry-run`.

## 4. Три рычага

### 4.1. Личный чат

- Максимум **2** сервисных касания (№1 через 5–7 дн., №2 ещё через ~7 дн.).
- Окно 10:00–19:59 МСК; ≤1 сообщение / 48 ч на дело.
- Сначала dry-run, потом пачки `--limit 40`.
- Документы: **личный чат MAX или кабинет после согласия** (не абсолютный запрет чата).

Микро-скрипт CH-1:

```text
Здравствуйте! Вы подписаны на наш канал про стаж и ИЛС — это полезно.
Если хотите продолжить именно вашу ситуацию, ответьте одним словом:
«ИЛС» — если выписка уже есть, или «Нужна проверка» — подскажем следующий шаг.

Сканы в публичный канал не присылайте. После согласия файлы можно
прислать в этот личный чат или загрузить в кабинете на сайте.
```

### 4.2. Канал MAX (мост)

На 10–14 дней посты с кнопкой **«Подать заявку»** на каждом:

1. «Канал читают — разбор делают в личном чате»
2. Как заказать ИЛС → ответ «ИЛС получил(а)» в чат
3. Что входит в диагностику 3 000 ₽ (без перерасчёта)
4. Родственнику: согласие и кто пишет в чат
5. «Если отложили — нормально» — мягкий возврат

Закреп — по [copy-channel-checklist-funnel](copy-channel-checklist-funnel-2026-09.md).

### 4.3. Сотрудник

После ответа клиента — **30–60 мин** в рабочие часы: один вопрос о препятствии + один следующий шаг. Оффер 3 000 ₽ — только при расхождении или явном запросе разбора.

## 5. Календарь 14 дней

| День | Действие |
|------|----------|
| 0 | Dry-run; счётчики корзин; исключить F; D → staff |
| 1 | Пост-мост «канал vs чат» |
| 1–2 | Касания №1: C → B → A/O (≤40/день) |
| 3–7 | Ответы на отклики; пост про ИЛС |
| 8–10 | Касание №2 молчащим |
| 11–12 | Пост про диагностику; дожим только ответивших |
| 13–14 | Archive после №2; отчёт FUNNEL + CSV |

## 6. Запрещено

- Третье DM без сигнала клиента  
- Реклама без marketing consent  
- Обещание перерасчёта / суммы  
- Сканы в публичный канал / форму сайта  
- Ночные касания и чаще 1 / 48 ч  
- LOSS сразу из тишины (сначала archive)
