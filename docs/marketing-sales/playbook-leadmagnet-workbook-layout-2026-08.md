## Принцип

Оформляйте лид-магнит как **рабочую тетрадь**, а не как рекламную брошюру: крупный шрифт, короткие действия, поля для ручных отметок и минимум текста на странице. Для аудитории важнее ясность и возможность распечатать PDF, чем «модный» дизайн.

---

## Инструмент

Для первой версии:

| Инструмент | Когда |
|---|---|
| **Canva** | Быстрее, проще для не-дизайнера, удобны шаблоны и PDF-экспорт — **оптимально для MVP** |
| **Figma** | Командная работа, компоненты, передача в вёрстку |
| **PowerPoint** | Офлайн-правки текста |
| **Word** | Допустим для строгой инструкции, хуже как лид-магнит |

Канон пайплайна:

```text
Макет → Canva
Исходные тексты и версии → Git (этот репозиторий)
Итог → PDF для печати + PDF standard для скачивания
+ облегчённая мобильная HTML на /chek-list-dokumentov/
```

## Размер и сетка

Канон подробнее: [playbook-pdf-print-readability-2026-08.md](playbook-pdf-print-readability-2026-08.md).

```text
Формат: A4, вертикальный
Размер: 210 × 297 мм
Поля: 18–22 мм
Рабочая ширина: 165–170 мм
Сетка: 1 основная колонка
Внутренний ритм: 8 / 16 / 24 pt
Страниц: 6–8
```

Не делайте две узкие колонки: пенсионерам трудно читать мелкий текст, особенно с телефона или на распечатке.

## Визуальная система

Стиль сайта `proverkastaza.ru`.

| Элемент | Рекомендация |
|---|---|
| Основной цвет | Тёмно-синий `#1B486C` |
| Акцент / действие | Зелёный `#1D6B4A` (статус — цвет + текст/иконка) |
| Предупреждение | Текст `#7A4D00` на светлом янтарном |
| Фон блоков | Светлый голубой `#EFF6FB` |
| Граница карточки | `#B7C6D2` |
| Основной текст | `#1F2933` |
| Шрифт | PT Sans / Arial / Noto Sans (макс. 2 гарнитуры) |
| H1 | 30–34 pt (ориентир 32 Bold) |
| H2 | 20–24 pt (ориентир 22 SemiBold) |
| Основной текст | **14 pt**, минимум 13 pt |
| Подписи | от 12 pt |
| Текст в таблицах | 12–13 pt |
| Межстрочный интервал | 1,35–1,5 |
| Чекбокс (печать) | 5–6 мм, строка ≥ 10–12 мм |
| Скругления | 10–14 px |
| Иконки | Линейные, простые, одного стиля |

### Не использовать

- мелкий текст;
- светло-серый текст на белом фоне;
- красный и зелёный как **единственный** способ различить статус;
- много декоративных фото пенсионеров;
- обещания «повысим пенсию», «вернём деньги», «восстановим стаж».

## Компоненты редактора

Создайте один раз и используйте на всех страницах:

```text
1. Верхняя полоса:
   логотип + «Проверка стажа» + «Рабочая тетрадь»

2. Номер страницы:
   «3 из 8»

3. Карточка шага:
   заголовок + 2–4 коротких действия

4. Чекбокс:
   □ действие выполнено

5. Информационный блок:
   ℹ Что это значит

6. Предупреждение:
   ⚠ Не отправляйте сканы в открытый чат

7. Карточка для заполнения:
   линии / поля для ручного ввода

8. CTA-блок:
   «Есть расхождение? Напишите: “Нужна проверка документов”»
```

Каждый компонент — минимум **40–44 px** высоты в цифровой версии и достаточно пространства для ручной отметки в печатной.

## Макет по страницам

Тексты для вёрстки — в [`pension-folder-checklist.md`](../../scripts/assets/leadmagnets/pension-folder-checklist.md). Кратко:

| № | Страница | Одна мысль |
|---|----------|------------|
| 1 | Обложка | Папка документов + 3 выгоды + дисклеймер СФР |
| 2 | Шаг 1 | Четыре раздела папки + янтарное предупреждение |
| 3 | Шаг 2 | Получить выписку ИЛС + дата |
| 4 | Сверка | Пять чекбоксов + зелёная развилка |
| 5 | Карточка | Форма спорного периода |
| 6 | Нет документов | Ориентиры + без гарантий архива |
| 7 | Следующий шаг | Две ветки + CTA в MAX |
| 8 | Словарь | 3–4 термина + контакты / QR на лендинг |

QR на стр. 3 — **только** на официальный материал Госуслуг по выписке ИЛС  
([справка Госуслуг](https://www.gosuslugi.ru/help/faq/checking_ils/100698)).  
QR на стр. 8 — на `/chek-list-dokumentov/` или `proverkastaza.ru`.

## Пошагово в Canva

1. Создайте дизайн `Документ A4`.
2. В настройках бренда сохраните 4–5 цветов и 1–2 шрифта.
3. Создайте первую страницу и добавьте логотип.
4. Сделайте стили текста: `H1`, `H2`, основной текст, подпись.
5. Нарисуйте шаблон карточки: белый фон, синяя граница слева, скругление 12 px.
6. Сделайте шаблон чекбокса: квадрат с границей минимум 2 px.
7. Дублируйте страницу и собирайте PDF из компонентов.
8. На каждой странице — номер и ссылка `proverkastaza.ru`.
9. Проверьте в масштабе 100% и распечатайте одну страницу.
10. Экспортируйте:
    - `PDF для печати`;
    - облегчённый `PDF standard` для скачивания;
    - исходник Canva для правок.

## Финальная проверка перед запуском

```text
□ Основной смысл понятен с первой страницы.
□ На странице не более одной основной мысли.
□ Основной шрифт не меньше 13 pt.
□ Документ читается без увеличения на телефоне.
□ Есть чёрно-белая версия, которую можно распечатать.
□ Чекбоксы и поля можно заполнять ручкой.
□ Нет персональных данных в примерах.
□ Нет обещаний перерасчёта, выплат или повышения пенсии.
□ CTA просит только написать ключевую фразу, не загружать документы.
□ QR-коды ведут на официальный источник или нейтральную страницу сервиса.
□ Дисклеймер: решение о пенсии/перерасчёте принимает только СФР.
□ Позиция: готовим документы и план — подаёт клиент.
```
