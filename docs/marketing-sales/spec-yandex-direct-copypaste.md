## Как вставить в Директ

1. [direct.yandex.ru](https://direct.yandex.ru/) → **Добавить** → **Кампанию** → **Мастер кампаний** или **Поиск**.
2. Счётчик Метрики **`111134477`** — выбрать цели `max_chat_click`, `lead_ok`.
3. Для каждой **группы** ниже: скопировать **ключи**, **2 объявления**, **ссылку с UTM**.
4. **Минус-слова** — блок «Общие для всех кампаний» в настройки кампании; дополнения — в группу при необходимости.
5. Проверить длину: заголовок ≤ **56** символов, текст ≤ **81** (указаны в таблицах).
6. ERID / маркировка — на стороне владельца.
