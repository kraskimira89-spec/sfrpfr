## 1. Цель

Собрать обратную связь о **понятности результата** и выполнении первого шага плана как **сервисное продолжение** уже оказанной диагностики — не как рассылку и не как рекламу.

Сервисный опрос ≠ согласие ПДн ≠ маркетинг. Реклама по сетям электросвязи — только с доказуемым предварительным согласием; согласие на ПДн может быть отозвано  
([разъяснения / практика по рекламе и согласиям](https://www.v2b.ru/documents/pismo-fas-rossii-ot-11-11-2019-df-98054-19/)).

## 2. Логика

```text
PDF опубликован → уведомление → открыт / подтверждён
→ опрос понятности (не одновременно с выдачей)
→ ответ → задача сотруднику или контроль первого шага
→ при необходимости отдельный запрос отзыва (выкл. по умолчанию)
```

## 3. Опросы

| Код | Когда | Канал MVP |
|-----|--------|-----------|
| `clarity` | PDF открыт (+48ч) или 2–3 дня после выдачи | **MAX кнопки** |
| `first_step` | 10–14 дней после `clarity=clear` | P1 |
| `quality` | после понятности | P1 |
| `review_request` | только явное согласие на публикацию | выкл. |

## 4. MAX clarity (этот релиз)

Текст:

> Здравствуйте! Удалось ли посмотреть результат диагностики?  
> Нам важно убедиться, что план действий понятен.

Кнопки → callback `svy:{token}` (в БД только `token_hash`, без case_id/ФИО в payload).

| Ответ | Действие |
|-------|----------|
| clear | `clarity=clear`; отменить unread; план first_step через 10 дн. (draft) |
| needs_help | задача сотруднику; отменить опросы; waiting_on=staff |
| question | задача high; отменить опросы |
| not_viewed | один повтор через 5–7 дн. |

Идемпотентность: повторный callback не дублирует задачи.

## 5. Ограничения частоты

- ≤ 1 сервисное сообщение / 48 часов на контакт;  
- ≤ 2 опросных касания на одну диагностику без нового обращения;  
- не слать, если ручной диалог сотрудника < 48 ч;  
- не слать ночью (22:00–08:00 Europe/Moscow);  
- draft → approve сотрудником;  
- `do_not_contact` / отзыв ПДн / hard_bounce → cancel all.

## 6. E-mail (P1)

Кнопка → страница подтверждения → «Подтвердить» (не фиксировать ответ одним GET из письма).
