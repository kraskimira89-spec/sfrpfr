**Дата:** 2026-09-25
**Канон бизнес-логики:** [35-sfr-client-chatbot-tz-v1.md](35-sfr-client-chatbot-tz-v1.md) (текст владельца, без правок).
**Не путать с:** `35-ai-document-intake-and-free-summary.md` (PR #41, ИИ-конвейер/HITL) — пересекается с этапами OCR и бесплатного резюме.

## Адаптация к проекту

- Канал — **MAX**. Везде, где в ТЗ «Telegram ID», читать `max_user_id`.
- Юридически значимые обращения подаёт **клиент** (или представитель) после согласования текста; правовую позицию утверждает специалист. Электронная приёмная СФР — вход через Госуслуги, статус по ID обращения.
- Пакет 8 000 ₽ — «сопровождение до завершения согласованного объёма работ», без гарантии решения госоргана/суда.

## As-is (проверено по коду 2026-09-25)

| Шаг | Есть | Разрыв |
|---|---|---|
| «Начать» + согласие | `services/client_pdn_consent.py`, отказ `pdn_consent:no`, запись в `clients` + `consents` | «Начать» = ПДн **и cookies** одной кнопкой; нет отдельного экрана (оператор, цели, сроки, отзыв); в `consents` нет `max_user_id` и ссылки на текст; загрузка файла в существующее дело не проверяет согласие; пустая версия считается согласием |
| Анкета | `integrations/max/intake.py` — кнопки: для кого, статус пенсии, проблема, ИЛС, устройство | Нет ФИО, года рождения, стажа, телефона, e-mail; варианты проблемы другие |
| Меню | `summary_keyboard`: кабинет, «какие документы», специалист | Нет «дело создано», нет кнопки лид-магнита (чек-лист уходит сразу после «Начать») |
| Документы | MAX → `upload_max_document` → `documents` + Storage + зеркало Диска | Нет вопроса о типе (`doc_type=None`), нет DOCX, нет ответа «Документ получен: «тип»» |
| Личное дело | UUID дела; папка Диска по **ФИО** | Нет номера `CASE-…`, нет подпапок 01–08, нет единого журнала (`case_messages`, `access_audit` — частично) |

## Этапы

**Правило владельца:** OCR, платежи и юрдокументы нового формата — только после проверки пути «согласие → анкета → документы → личное дело» на 2–3 тестовых клиентах.

| Этап | Объём | Приёмка |
|---|---|---|
| **A. Вход** | Уведомление у «Начать»; отдельный экран ПДн (без cookies); запись с версией и `max_user_id`; без согласия не принимать анкету и файлы | Тест-клиенты: без согласия ничего не принимается; согласие видно в деле |
| **B. Анкета** | 8 вопросов по одному; колонки в БД; меню «дело создано» (4 пункта) | Анкета в деле, видна в админке |
| **C. Документы** | Тип документа; DOCX; «Документ получен»; событие в журнале | Файл с типом в деле и на Диске |
| **D. Личное дело** | Номер `CASE-YYYY-NNNNNN`; папка Диска по номеру, подпапки 01–08; `audit_log` | Папка без ФИО; журнал отвечает «на каком этапе дело» |
| E. Проверка и отчёт | Бесплатная краткая диагностика; PDF/DOCX/MD (стыковка с PR #41/#42) | После A–D |
| F. 5 000 / 8 000 | Обращения, напоминания, разбор ответа, эскалация | После E |

## Открытые решения владельца

1. Цена подробного анализа: оставить 3 000 ₽ (DIAG) или иначе.
2. Реквизиты оператора на экране согласия: ООО «ПОД ПРИСМОТРОМ», ИНН 8905066468 (с сайта) — нужны ОГРН и адрес.
3. Папки Диска: переход с ФИО на номер дела (с миграцией существующих папок) — да/нет.
4. Лид-магнит «как самостоятельно проверить стаж»: новый PDF или временно текущий чек-лист.
