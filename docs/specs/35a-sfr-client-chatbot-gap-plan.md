## Этапы

**Правило владельца:** OCR, платежи и юрдокументы нового формата — только после проверки пути «согласие → анкета → документы → личное дело» на 2–3 тестовых клиентах.

| Этап | Объём | Приёмка |
|---|---|---|
| **A. Вход** | Один экран согласия с реквизитами оператора; запись с версией и `max_user_id`; без согласия не принимать анкету и файлы | Тест-клиенты: без согласия ничего не принимается; согласие видно в деле |
| **B. Анкета** | 8 вопросов по одному; колонки в БД; меню «дело создано» (4 пункта) | Анкета в деле, видна в админке |
| **C. Документы** | Тип документа; DOCX; «Документ получен»; событие в журнале | Файл с типом в деле и на Диске |
| **D. Личное дело** | Номер `CASE-YYYY-NNNNNN`; папка Диска `ФИО — номер — дата`, подпапки 01–08; переименование старых папок; `audit_log` | Папки в новом формате; журнал отвечает «на каком этапе дело» |
| E. Проверка и отчёт | Бесплатная краткая диагностика; PDF/DOCX/MD (стыковка с PR #41/#42) | После A–D |
| F. 5 000 / 8 000 | Обращения, напоминания, разбор ответа, эскалация | После E |
