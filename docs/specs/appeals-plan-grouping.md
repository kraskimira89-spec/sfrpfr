# План обращений: группировка и шапки

**Правило сервиса (не всеобщий юрзапрет):** одно обращение — один конкретный адресат и одна группа однородных вопросов. Несколько однотипных проблем можно объединять; разнородные — нельзя. Одного совпадения ведомства недостаточно.

## Маршрут

| Ступень | Что делает ИИ / сотрудник |
|---|---|
| 5 | План обращений в подробном разборе (таблица + почему объединено/разделено) |
| 6 | Согласование плана клиентом; сотрудник может перегруппировать до согласия |
| 8 | Отдельный Word на каждое согласованное обращение; gate шапки |
| 11–12 | Доп. проекты — **новая версия** плана, без молчаливой подмены согласованного |

Код: `src/sfrfr/services/appeals_plan.py`, шапка DOCX — `appeal_docx.py` + `header_gate`.

## Версии

Новые документы меняют рекомендации только через новую версию плана и повторное согласование затронутого. Согласованный snapshot не перезаписывать молча.
