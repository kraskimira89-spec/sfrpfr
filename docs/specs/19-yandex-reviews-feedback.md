## 1. Цель

Получать **реальные** отзывы клиентов о сервисе «Проверка стажа» в карточке Яндекс Бизнеса / Яндекс Картах так, чтобы отзывы проходили модерацию Яндекса, повышали доверие и не нарушали 152-ФЗ, оферту и запреты ТЗ-18 (без накруток, без гарантий перерасчёта, без ПДн в публичных текстах).

## 2. Не является целью

- купить или «накрутить» отзывы;
- просить сотрудников, родственников, друзей;
- давать скидку / подарок / бонус за отзыв или за показ скриншота;
- просить старых клиентов оценить «новую» компанию / новый адрес по памяти;
- публиковать на сайте фейковый рейтинг / Schema `AggregateRating` без реальных данных;
- писать в отзыве или ответе ФИО клиента, номер дела, сумму пенсии, СНИЛС, диагнозы.

## 3. Когда просить отзыв

| Триггер | Действие |
|---------|----------|
| Услуга оказана, диалог спокойный, клиент получил результат работы **сервиса** (не решение СФР) | Одна короткая просьба в MAX (по желанию + QR) |
| Клиент не ответил и не отказался | Напоминание **не раньше чем через 3 дня**, не чаще одного раза, только если уместно |
| Клиент отказался, молчит после напоминания или негатив | Сразу стоп |
| Лид без оплаты / спор / ожидание решения СФР | **Не** просить отзыв |

Важно: отзыв — о **работе сервиса** (ясность, сроки ответа, удобство канала), а не «СФР повысил пенсию» и не гарантия результата.

## 4. Как просить (по статье Яндекса)

1. Сделать процесс простым: **прямая ссылка** на форму отзыва (из кабинета «Отзывы» / промоматериалы), без сокращателей.
2. Задать **направляющие вопросы** без подсказки «правильного» ответа.
3. Напомнить один раз через 1–3 дня, без серии звонков и давления.
4. Скачать **промоматериалы** в Яндекс Бизнесе (QR / визитка) для офлайн или вложения в переписку при необходимости.

## 5. Каналы

| Канал | Роль |
|-------|------|
| MAX | Основной: шаблоны просьбы и напоминания |
| Email / телефон | Только если клиент сам предпочитает и есть согласие на связь |
| Сайт WordPress | Не размещать агрессивный pop-up «оставьте отзыв»; на `/kontakty/` — мягкая ссылка **после** появления рабочей URL формы |
| Яндекс Бизнес UI | Модерация отзывов, ответы компании, промоматериалы |
| Кабинет / API | Не принимать текст отзыва на WP; публичный отзыв — только в Яндексе |

## 7. Процесс оператора (чеклист)

### 7.1. Разовая настройка (P0)

1. Войти в https://yandex.ru/sprav/234170727274/
2. **О компании → Отзывы** — скопировать ссылку на форму («Получить ссылку» / открыть «Написать отзыв» на Картах и скопировать URL).
3. **О компании → Промоматериалы** — скачать QR (PNG) и при необходимости макет визитки; положить **вне git** или в `secrets/` (не коммитить персональные экспорты).
4. Записать URL в `secrets/yandex-business-review.env` как `YANDEX_BUSINESS_REVIEW_URL=…`
5. Подставить URL в шаблоны при первой отправке (или держать рядом в заметке оператора).

### 7.2. На каждом завершённом деле

1. Убедиться, что клиент **реальный** и услуга по договору оказана.
2. Отправить шаблон «Первая просьба» из `review-request-templates.md` в MAX.
3. Отметить в журнале: дата, `case_id` (внутренний), статус `asked` — **без** ФИО в публичных файлах репо.
4. Через 1–3 дня при отсутствии отзыва — шаблон «Напоминание» **один раз** → статус `reminded` или `done` / `declined`.
5. Новый отзыв в кабинете — ответить по `review-reply-templates.md` в срок до 2 рабочих дней.

## 8. Правила текста просьбы и ответа

**Можно:** поблагодарить; спросить про ясность шагов, удобство MAX/кабинета, полноту чек-листа; дать ссылку; напомнить, что решение СФР принимает СФР.

**Нельзя:** «оставьте 5 звёзд», «напишите что пенсия выросла», «за отзыв скидка», «покажите скрин — дадим бонус», копировать чужие отзывы, указывать чужие ПДн.

## 9. Метрики (без ПДн)

- число отправленных просьб / напоминаний за месяц;
- число новых опубликованных отзывов в Яндексе;
- доля ответов компании на отзывы (цель 100%);
- жалобы/отказы клиентов на просьбу (если фиксируются оператором).

Не связывать публичный текст отзыва с `case_id` в открытых документах.

## 12. Стоп-факторы

Немедленно остановить кампанию просьб, если:

- предложен бонус/скидка за отзыв;
- просьба уходит неклиентам или «своим»;
- в шаблонах появляются гарантии перерасчёта;
- в ответах компании всплывают ПДн клиента.
