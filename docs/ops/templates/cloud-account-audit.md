## Признаки принадлежности к SFRFR

Отметить, что именно связывает ресурс с проектом:

- [ ] labels/metadata содержат `project=sfrfr` / `sfrfr-…`;
- [ ] DNS A/CNAME домена `proverkastaza.ru` (или поддомена) указывает на IP ресурса;
- [ ] на ресурсе найдены каталоги/сервисы из документации (`/opt/sfrfr`, `/opt/sfrfr-supabase`, Apache vhosts);
- [ ] hostname VM начинается с `sfrfr-…`;
