## Вход / действие / запрет / результат (шаблон)

Для каждого основного процесса:

1. **Вход:** сигнал(ы) клиента + доступный контекст дела.  
2. **Допустимо:** проверка фактов, регистрация по процессу, выдача оплаченного, пауза.  
3. **Запрещено:** ложный успех, авто-offer после отказа, подгонка стажа, продажа на страхе.  
4. **Результат:** подтверждённое действие ИЛИ честная невозможность — не намерение.
