# Ops: разбор диалогов clarity (FUNNEL-5)

**Задача:** [FUNNEL-5](https://tracker.yandex.ru/FUNNEL-5)  
**Канон:** [playbook-sales-clarity-funnel.md](../marketing-sales/playbook-sales-clarity-funnel.md)  
**Шпаргалка:** [playbook-staff-new-lead-cheatsheet.md](playbook-staff-new-lead-cheatsheet.md)

## Цель

Проверить 5–10 реальных диалогов lead/qualify: ясность оффера, канон цены, next step в кабинете.

## Когда

- После внедрения канона clarity (staff cabinet).
- Повтор — раз в месяц или после смены скрипта.

## Выборка

| Критерий | Как |
|----------|-----|
| Объём | 5–10 дел за 2 недели |
| Этапы | `new`, `in_touch`, колонки lead/qualify |
| Источник | Admin → реестр / канбан (без экспорта ПДн) |
| case_ref | Только последние 4 символа id в отчёте |

## Чеклист на каждый диалог

| # | Вопрос | да / нет / н/п |
|---|--------|----------------|
| 1 | Первый ответ в SLA 30–60 мин (рабочие часы)? | |
| 2 | Начали с человека, не с цены? | |
| 3 | Назвали диагностику 3 000 ₽ по канону (§4)? | |
| 4 | Без «всего лишь» / оправданий цены? | |
| 5 | Не обещали перерасчёт / сумму пенсии? | |
| 6 | Завершили разговор **одним** next step? | |
| 7 | В кабинете заполнены `next_action` + дата? | |
| 8 | При «дорого» — чек-лист, не дожим? | |
| 9 | Сканы не просили в открытый чат? | |
| 10 | Позиция подачи: клиент подаёт сам, решает СФР? | |

**н/п** — не применимо (например, клиент не дошёл до цены).

## Шаблон отчёта (комментарий в FUNNEL-5)

```text
## Clarity dialog review — YYYY-MM-DD

Период: … — …
Диалогов: N

| # | case_ref | SLA | цена канон | next step | замечание |
|---|----------|-----|------------|-----------|-----------|
| 1 | … | да | да | нет | пустая дата |

Вывод: …
Узкое место: …
Next step: …
```

## Триггеры эскалации

- < 70% диалогов с каноном цены → разбор с оператором, §4 playbook.
- < 50% с заполненным next step → напоминание + [FUNNEL-2](https://tracker.yandex.ru/FUNNEL-2).
- Обещание перерасчёта → STAZH (качество), не FUNNEL.

## Закрытие FUNNEL-5

После отчёта по 5–10 диалогам + вывод + next step → resolution «Решен».  
Регулярный разбор — новый слот FUNNEL-5 или эпик FUNNEL-1.
