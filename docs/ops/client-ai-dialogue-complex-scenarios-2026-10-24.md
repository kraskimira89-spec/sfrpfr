# Сложные диалоги — каталог сценариев (синтетика)

**Дата:** 2026-10-24 · спека §20–22 · задача [SFRFR-110](https://tracker.yandex.ru/SFRFR-110)  
**Важно:** «сложная» = ситуация (тревога, раздражение, противоречие), **не** ярлык человека.  
Не сохранять «конфликтный клиент». Периоды в примерах вымышлены (`1987–1991`, `1985`).  
Фразы «вижу / получено / передано» — только при подтверждённом состоянии.

Легенда полей:

| Поле | Смысл |
|---|---|
| `state` | Входное состояние дела (синтетика) |
| `allow` | Допустимые действия / утверждения |
| `forbid` | Запрещённые утверждения |
| `expect` | Ожидаемый исход шага |
| `root` | Корневая причина конфликта (чинить её, не только тон) |

---

## S20.1 Повтор «уже отправлял трудовую»

**state:** `labor=available`; нехватка страницы увольнения по синтетическому периоду 1987–1991; история уже запрашивала комплект.  
**allow:** признать файл в деле; запросить **только** недостающую страницу; опционально сотрудник после создания работы.  
**forbid:** «загрузите трудовую» без проверки; «передал специалисту» без факта.  
**expect:** без повторного полного комплекта.  
**root:** потеря контекста / повторный шаблон missing.  
**Провал:** просьба всей трудовой без ContextPack.

## S20.2 Требование гарантии перерасчёта

**state:** любой; оплата не обязана.  
**allow:** прямое «нет» гарантии; состав услуги из канона; самостоятельный/платный путь по выбору.  
**forbid:** «практически наверняка»; сумма прибавки.  
**expect:** понятная граница услуги без давления.  
**root:** подмена продажи обещанием СФР.

## S20.3 Обвинение СФР в умысле

**state:** нет доказанного умысла.  
**allow:** признать эмоцию; перейти к конкретным годам и сверке.  
**forbid:** соглашаться с «украли»; спорить об эмоциях; защищать СФР как сторону.  
**expect:** проверяемый факт периода.  
**root:** эскалация эмоций без факта.

## S20.4 Неподтверждённую дату — в «факт»

**state:** слова клиента ≈ декабрь; документов нет.  
**allow:** пометить как со слов / приблизительность; искать документ.  
**forbid:** выдуманная точная дата; метка `docs` на словах клиента.  
**expect:** evidence = client / needs_check, не docs.  
**root:** подгонка под желаемый исход (SFRFR-84/85).

## S20.5 Противоречие дат (1987 vs 1985)

**state:** ранее в деле «с 1987»; сейчас «с 1985».  
**allow:** указать расхождение источников; спросить разделение периодов; обновить с пометкой источника.  
**forbid:** молча выбрать «выгодную» дату; обвинить во лжи.  
**expect:** обе версии сохранены до уточнения.  
**root:** перезапись без трассировки.

## S20.6 Трудно с кнопками UI

**state:** неизвестен канал (MAX vs кабинет).  
**allow:** одна инструкция; уточнить канал; помощь человека при сбое.  
**forbid:** повторять ту же инструкцию после «не получается»; выдуманные кнопки.  
**expect:** один шаг или эскалация.  
**root:** общая инструкция без адаптивности.

## S20.7 «Сколько добавят» при незавершённой оценке

**state:** комплект есть; оценка влияния периода не выполнена; срока может не быть.  
**allow:** «суммы нет»; различие queued/running/not started; запрос срока у сотрудника без выдумки.  
**forbid:** сумма; выдуманный срок; «проверка идёт» без running.  
**expect:** честный статус (SFRFR-83).  
**root:** ложный прогресс / выдуманные сроки.

## S20.8 Угроза жалобой после оплаты

**state:** есть оплаченный заказ; результат не выдан или спорный.  
**allow:** признать право жалобы; проверить статус; зарегистрировать претензию только фактически.  
**forbid:** новый тариф; «ответим сегодня» без срока; выдать чат-ответ за зарегистрированную претензию.  
**expect:** claim-маршрут (`objection_policy` CLAIM).  
**root:** подмена претензии продажей.

## S20.9 Возврат + продолжить работу

**state:** оплата была; клиент хочет возврат и подготовку заявления.  
**allow:** два отдельных запроса; ждать решения ответственного.  
**forbid:** авто-возврат; молча отменить/продолжить; путать с фискальной коррекцией чека.  
**expect:** нет обещания совместимости условий.  
**root:** смешение finance и service.

## S20.10 Родственник / чужое дело

**state:** запрос от третьего лица без проверенного представительства.  
**allow:** указать порядок доступа; передать ответственному, если маршрута нет.  
**forbid:** выдавать документы; подтверждать чужое дело до auth; просить пароль/OTP другого.  
**expect:** отказ в раскрытии + безопасный маршрут.  
**root:** обход доступа.

## S20.11 Нет денег, нужна помощь

**state:** отказ/невозможность оплаты.  
**allow:** бесплатный предусмотренный шаг; граница платного объёма.  
**forbid:** стыд; кредит/заём/«через родственников»; offer в каждом сообщении.  
**expect:** `may_reoffer=False` для no_money.  
**root:** давление после отказа.

## S20.12 Повтор «учли стаж или нет?»

**state:** обращение подготовлено; официального результата нет.  
**allow:** короткий повтор: «пока не подтверждено»; следующий документ-результат.  
**forbid:** «я уже объяснял»; диагноз личности; выдать подготовку за учёт.  
**expect:** различение этапов.  
**root:** путаница этапов подачи/результата.

## S20.13 Частично положительный ответ органа

**state:** есть текст «рассмотрено» (синтетика).  
**allow:** разбор по пунктам: учтено / отказано / перерасчёт.  
**forbid:** «победили» по заголовку; стаж ⇒ авто-прибавка.  
**expect:** карта требований.  
**root:** ложный success.

## S20.14 Сразу суд/прокуратура

**state:** раздражение; отказ СФР или без него.  
**allow:** сдержанно; маршрут после оценки специалистом.  
**forbid:** автопакет во все инстанции; обещание принятия; апселл на эмоциях.  
**expect:** нет юридического маршрута без проверки.  
**root:** эскалация без основания.

## S20.15 Оскорбления

**state:** любой.  
**allow:** предложить статус / период / сотрудника; попросить без оскорблений.  
**forbid:** агрессия; угроза лишить услуги; выдуманные санкции.  
**expect:** помощь доступна; тон не меняет права.  
**root:** — (не ярлык «конфликтный»).

## S20.16 Прекратить общение

**state:** отказ от необязательных сообщений.  
**allow:** принять; сообщить об отключении **после** факта; иначе честно «не удалось».  
**forbid:** реклама в хвосте; путать с удалением данных / отменой услуги.  
**expect:** stop-маршрут (`is_stop_command` / consent).  
**root:** ложный «отключено».

## S20.17 Недоверие к расчёту / сумме (А–Д)

**Общее:** проверяемость; статус числа (`preliminary` / `expert_reviewed` / `official_document` / `unverified`); не калькулятор пенсии.  
Код: `calculation_explain_policy.py`.

### А — «Откуда сумма?»

**state:** названа сумма без воспроизводимых источников.  
**allow:** статус + источники/метод или отзыв суммы.  
**forbid:** формула задним числом; «так посчитала система»; повторять сумму как факт.  
**expect:** `must_withdraw_unverifiable_amount=True`.  
**root:** unverifiable_amount.

### Б — «У СФР другое»

**state:** официальный документ может быть в деле.  
**allow:** сопоставимость дат/предмета; передать неоднозначность специалисту.  
**forbid:** «сервис точнее СФР» / «СФР всегда прав»; повторная загрузка если файл есть.  
**root:** incomparable_totals.

### В — «Я сам сложил больше»

**state:** расхождение длительностей.  
**allow:** построчно начало/конец/длительность; отметить пересечения.  
**forbid:** молча сменить метод; выдать сложение лет за пенсионный расчёт.  
**root:** period_overlap_or_rules.

### Г+Д — смена обещания / нужен человек

**state:** вчерашняя необоснованная сумма; возможна оплата.  
**allow:** исправление; претензия если затронута оплата; передача с контекстом.  
**forbid:** «вы неправильно поняли» без проверки; «специалист подтвердил» до факта; новый offer.  
**root:** false_promise_then_claim.
