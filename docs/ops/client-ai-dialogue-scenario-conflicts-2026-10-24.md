# Конфликты и пересечения сценариев

Дата: 2026-10-24 · SFRFR-110

## Приоритет обработки (одна реплика)

1. Непосредственная опасность (safety)  
2. Доступ / ПДн  
3. Stop / отказ / настройки коммуникаций (в своей области)  
4. Претензия / возврат / удаление данных  
5. Подтверждённый существенный срок (нейтрально)  
6. Предмет дела (расчёт, противоречие, документы)  
7. Коммерческий offer — только если уместно и не запрещён

Сначала — уже известные сведения; не выспрашивать заново.

## Контракт регистрации (не путать)

| Событие | Можно сказать клиенту |
|---|---|
| сообщение получено | «получили сообщение» |
| запрос сохранён | «запрос сохранён» |
| внутренняя работа создана | «задача создана» ≠ претензия принята |
| претензия зарегистрирована | только после успеха процесса |
| ответственный назначен | после факта |
| решение принято / действие выполнено | после факта |

Намерение: «Попробую зарегистрировать…»  
Успех / ошибка — отдельными фразами.

## Повторный offer (единое правило)

Существенное изменение обстоятельств **само по себе** не отменяет отказ от предложения и запрет коммерческих сообщений.  
Обсуждение — по инициативе клиента или согласованному напоминанию.  
Сервисный факт по делу можно сообщить **без** продажи.

## Независимые области состояния

| Область | Примеры |
|---|---|
| Пенсионный вопрос | проверяется / расхождение / официальный результат |
| Документы | получены / нечитаемы / противоречат / проверены |
| Заказ | выполняется / передан / завершён |
| Offer | не предложено / отклонено / согласовано |
| Претензия | получена → … → решение исполнено |
| Коммуникации | обычный / пауза / коммерция запрещена |
| Передача сотруднику | запрошена → выполнена |

Не сливать в «клиент отказался» / «дело закрыто».

## Новые факты (единая цепочка)

```text
новый документ/уточнение → источник → фиксация → dependents
→ needs_recheck → повторная проверка → обновлённый результат → объяснение
```
