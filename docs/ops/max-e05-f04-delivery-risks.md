# Риски доставки outbox / MAX (вне скоупа E05/F04 wire)

Связанный блок — не маскировать внутри интеграционного PR политики.

| Риск | Наблюдение | Почему вне среза |
|---|---|---|
| HTTP ok ≠ прочитано | `MaxBotClient.send_message` подтверждает транспорт, не read receipt | Нужен отдельный контракт статусов |
| Enqueue успех ≠ sent | `enqueue_max_delivery` → `pending` | Уже отражено в тесте; архитектура worker без изменений |
| Частичный сбой outbox | process падает после mark / до mark | Требует идемпотентности/ретраев outbox |
| Конкурентность worker | несколько process_pending_outbox | Общая переработка concurrency запрещена ТЗ |
| Дубль при handler + worker | если одновременно `_reply` и outbox | Срез: для ACTION_E05_F04 только outbox |
| Неизвестный исход транспорта | timeout / 5xx без явного fail | Диагностические тесты + отдельный PR статусов |
| Отсутствие реального system-ack | Null-адаптер → нет перехвата | Хранение доказательств / идемпотентность — следующий приоритет |
