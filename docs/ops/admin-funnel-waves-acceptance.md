# Приёмка волн admin-воронки (A0 → A → B → C)

**Кабинет:** https://admin.proverkastaza.ru/  
**Правило:** смотреть **открытую карточку дела**, не реестр. После деплоя — Ctrl+F5.

## A0 — честное резюме в чат

| Проверка | Ожидание |
|---|---|
| Docs-находки → «Подставить резюме» | Есть basis/период; офер DIAG один раз; без `/help` |
| Только анкета (северный стаж) | «Недостаточно данных», без 3000 |
| DIAG paid | Без повторного офера |

SHA A0: `d1022b3b` (PR #289).

## A — ступени 2→3

| Проверка | Ожидание |
|---|---|
| Ступень «Документы» | Файлы, чек-лист, запрос документов; без DocumentCheckPanel |
| Ступень «Первичная проверка» | CaseWorkRoute + «Проверить документы» + резюме |
| После успешной проверки | Ступень 3 раскрыта (свежий result) |

| `analysis_payment` | Счёт DIAG; disabled если paid/open |

## C — пилот Трекера (1 is_test)

| Проверка | Ожидание |
|---|---|
| `TRACKER_CASE_SYNC_ALLOWLIST` | Только выбранный case_id |
| `POST .../tracker-case-sync/enqueue` | Строка в `tracker_sync_outbox` |
| `POST .../tracker-case-sync/tick` | Нужны field ids + OAuth; иначе явная ошибка |
| Глобальный `TRACKER_CASE_SYNC_ENABLED` | **остаётся 0** без отдельного решения |

Операционные блокеры (lead CASE, локальные поля) — см. `docs/TRACKER/release-package-case-sync-pilot.md`.

## Вне приёмки

Глобальный sync, боевые платежи 3/5/8к на живых, массовые рассылки, обещания перерасчёта.
