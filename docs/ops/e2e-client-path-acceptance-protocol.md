# Протокол сквозной приёмки клиентского пути

**Версия:** 2026-10-24
**Связано:** SFRFR-100, [`project-readiness-passport-2026-10-24.md`](./project-readiness-passport-2026-10-24.md)
**Цель:** один подтверждаемый проход
`заявка → кабинет → документы → эксперт → оплата и чек → результат клиенту`
с различением реализовано / проверено / принято / заблокировано.

**Запреты:** без ПДн в отчёте; без секретов; боевые платежи — только после «да, платим N»; новый платёж для воспроизведения дубля 8000 — без согласования **не** проводить.

---

## Легенда статусов шага

| Код | Значение |
|---|---|
| R | реализовано (код есть) |
| V | проверено (датированный прогон) |
| A | принято владельцем/Стратегом |
| X | заблокировано |

Итог протокола = **принято**, только если все обязательные шаги имеют **A** (или явный waiver владельца).

## Минимальный «зелёный» набор без боевых полных сумм

Если владелец **не** даёт «да, платим» на 3/5/8k в этом прогоне:

- шаги 1–4 и 7 обязательны для **A**;
- шаг 5 помечается **X** или waiver «оплаты приняты ранее по battle-протоколам + отдельный статус B1»;
- **не** писать «путь принят полностью», пока B1/B2 открыты и 5 не закрыт waiver’ом.
