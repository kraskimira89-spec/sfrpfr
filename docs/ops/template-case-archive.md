# Шаблон: архив дела (staff)

Внутренний артефакт качества после диагностики / разбора документов.  
**Не** публичный PDF клиенту. Без полных СНИЛС, паспортов, адресов.

Связано: `ASSISTANT_SYSTEM` (`src/sfrfr/ai/prompts/__init__.py`) · CRM [playbook-staff-cabinet-crm.md](playbook-staff-cabinet-crm.md) · воронка ясности.

---

## Когда заполнять

- После первичной сверки документов (диагностика 3 000 ₽ или разбор в карточке).
- Перед передачей дела другому сотруднику / эскалацией в STAZH.
- Когда AI-помощник эксперта выдал блок «Архив дела» — сверить и вставить в `next_action` / заметку карточки.

---

## Канон этапов работы по делу

```text
1. Опознать тип файла(ов)
2. Комплект 4 слоёв: ИЛС · трудовая/ЭТК · (если пенсия) справка СФР · банк за 12 мес.
3. Таблица периодов / расхождений (A vs B)
4. Точечный дозапрос только по спорным местам
5. Черновик заявления/запроса + «проверить эксперту»
6. Клиент подаёт сам; мы сопровождаем шагами
7. Внутренний «архив дела» (этот шаблон)
```

---

## Поля карточки (копипаст)

```text
## Архив дела

**Кратко проблема:** …
**Сегмент:** север | педагогика | север+педагогика | работающий пенсионер | ветеран | не учли период | иное
**Документы в деле:** ИЛС □ · трудовая/ЭТК □ · справка СФР □ · банк 12 мес. □ · иное: …
**Ключевые расхождения:** …
**Недостаёт (точечно):** …
**План / следующий шаг:** …
**Черновик обращения:** есть □ / нет □ (проект, правит эксперт)
**Граница:** суд/прокуратуру не ведём; подаёт клиент; решение — СФР
**Статус:** черновик для эксперта / готово к клиенту
```

---

## Ветки чеклиста эксперта

| Сегмент | На что смотреть |
|---------|-----------------|
| Север / РКС / МКС / приравненные | Формулировки периодов; не считать льготу автоматом |
| Педагогика | Записи должностей/учреждений; отдельная линия от севера |
| Работающий пенсионер | Статус работы; сверка выплат СФР ↔ банк; не обещать индексацию |
| Ветеран | Только по явным документам; вывод эксперту |
| Разрозненные сканы трудовой | Попросить один PDF / нумерацию страниц |

НКО / налоговые уведомления вне B2C-ядра — не смешивать с типовым архивом стажа.
