## SFRFR-101 — безопасная vs требующая разрешения

| Часть | Действия | Согласование |
|---|---|---|
| **A — безопасно (сделано/можно)** | QA `lead-staff-e2e.md`; smoke health + POST без токена → 401 | не нужно |
| **B — нужно разрешение** | полный lead с `PUBLIC_LEAD_TOKEN` → case в staff | один запрос ниже |

### Точный запрос на часть B

- **Среда:** production API `api.proverkastaza.ru`, WP форма или curl с токеном с VPS.
- **Сущности:** один тестовый lead (`is_test` / явная пометка), без реальных ПДн клиента.
- **Действия:** создать заявку → убедиться `case_id` → дело в staff канбане `new`.
- **Последствия:** строка в БД cases/clients; возможное MAX-уведомление staff.
- **Очистка:** пометить/закрыть тестовое дело как lost/test; не слать клиентам.
