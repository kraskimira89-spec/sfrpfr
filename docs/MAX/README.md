## Канон (с 2026-08-26)

**Личного кабинета клиента в MAX нет и не будет.**

| Канал | Роль |
|-------|------|
| Личный чат MAX | Вся переписка: диагностика, подсказки, вложения, «Позвать специалиста», код входа |
| Личный кабинет **на сайте** | Согласие, документы, оплата, статус (`CABINET_PUBLIC_URL`) |
| `/app/` (mini-app) | Техзаглушка / legacy URL в настройках бота; **не** клиентский кабинет |

- Не направлять в «кабинет MAX» / mini-app как ЛК.
- В боте CTA: **«Кабинет на сайте»** → только веб-URL (`cabinet.proverkastaza.ru`).
- Документы: предпочтительно кабинет на сайте; файл **в чат** — **принимаем** + мягкий CTA сайта.
